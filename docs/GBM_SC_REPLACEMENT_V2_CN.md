# GBM 单细胞来源替换 v2

## 本轮问题
用户要求替换 Darmanis2017 和 Neftel2019，优先质量与足够细胞量。旧结果留作历史，新主来源采用 CARE 2025（GSE274546），不将发表较新的旧数据整合图谱冒充新队列。

## 输入与范围
原始研究：[Spitzer et al., Nature Genetics 2025](https://www.nature.com/articles/s41588-025-02168-4)；处理后计数：[GSE274546](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE274546)。注释和临床表使用[作者仓库固定提交](https://github.com/dravishays/GBM-CARE-WT/tree/383b0a320f0993a4529167cdb591dac63e103674)。

- 10x 单核 RNA 测序，121 标本、59 患者，全部 IDHwt；作者质控后 429,305 个细胞核。
- 作者逐细胞 ID 与临床 Sample ID 精确连接；按临床状态区分初发/复发，不能从 T1/T2 编号推断。
- 初发：56 患者、56 标本、206,675 核，作为主分析。
- 复发：65 标本，按真实患者 ID 合并多次采样，作为同队列补充，绝不当独立验证。
- 全部 142 候选基因；已有代谢物、bulk RNA、关联效应和 P/q 原样保留。

## 实际结果
当前为数据获取与计算阶段，尚未生成新来源结论。429,305 是作者质控注释覆盖量，不是尚未检查的原计数矩阵总细胞数。

## 新手解释
细胞量决定细胞类型覆盖，患者数决定跨患者稳定性。这里用患者等权汇总，避免一个患者贡献大量细胞后主导结果。单核 RNA 与完整单细胞 RNA 有技术差异，不直接比较旧/新归一化表达绝对值。

## 限制/反证
CARE 是可再次手术的纵向病例队列，具有临床选择偏倚。它提供细胞表达来源背景，不能证明代谢物来源或酶活。初发与复发属于同一研究，不能声称两队列独立复现。作者 Other 类保留描述但不参与明确细胞来源排名。没有新增聚类或标签推断。

## 当前决定
采用一个较新的大型、可审计队列替换两项旧主来源。先完整交付 CARE；并非为凑两项独立队列而降低纳入质量。

备选筛查：GBmap 扩展版 1,135,677 细胞来自 26 个作者队列，包含旧来源，不整包称新数据；其中 Abdelfattah2022 有 16 GBM 患者、初发/复发混合。SNUH 有多区域与 CITE 重复模态，需额外去重。上述均未混入本轮主分析。
