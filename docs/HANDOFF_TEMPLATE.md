# 癌种批次交接模板

- 癌种 / 账号 / 分支 / commit：
- RUN_ID / server165输出路径：
- 输入版本、来源与SHA256：
- 独立统计单位及确认依据：
- 本批计划 / 可评估数 / 检验家族：
- 已完成：实际文件、关键数值、必要验证
- 候选判断发生的变化：
- NOT_RUN：尚未做
- NOT_EVALUABLE：确实缺条件与依据
- ACCESS_BLOCKED：来源与错误；不是阴性
- 反证、限制与独立性：
- 下一项最小工作及负责人：
- 新增公共代码/映射及影响范围：

不上传患者级文件；本模板每癌种每批各存一份，不由两个账号同时改同一日志。
