# 项目背景与当前状态

## 三轮交付

第一轮：完整候选关系、可算关联、基础影响检查，功能和现成外部信息并行；第二轮：候选证据、反证和研究增量比较；第三轮：每条重点轴只补最可能改变判断的证据。任何未做与不可评估必须分开。
