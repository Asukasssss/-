# PDAC 三队列细胞来源分析 v1

用户要求至少3套质量合适的单细胞用于相关基因来源。选择GSE263733、GSE278688、GSE242230作者新增eusfnb子集。以最新11对、307特征配对分析中原始P<0.05的51条作重点；仅复用已存在的直接/条件映射，不把旧42名单或173基因当成51条全部映射完成。

分析前规则：
- 三队列分别分析；GSE263733仅Pm0/Pm1原发肿瘤；GSE278688仅Tumor，排除PBMC；GSE242230仅eusfnb/tumor_primary、filtered=False且作者细胞类型非空。
- 原始计数基于全部基因计算每个患者/样本×细胞类型总UMI，候选计数汇总后计算log1p(CPM)。同时计算每个患者组内的检测比例，再等权汇总患者；不让大样本细胞数主导来源排序。
- 每个患者×类型至少20细胞，来源排序至少3个有效患者/样本，且至少3个单位检测到该基因。缺基因、不足患者均保留NA及状态，不当零表达。25例eusfnb样本按作者独立样本描述作为单位，未再推断重复患者。
- 标准10x矩阵存在重复符号时，不任取一行或加总成未经核实的基因；目标符号仅在唯一对应时分析，否则保留GENE_ABSENT_OR_AMBIGUOUS。全部原矩阵行仍纳入总UMI分母。
- 主输出仅描述表达来源，无差异P/q。跨队列2/3或3/3最高表达类型一致仅称描述一致，不称肿瘤差异显著复现或机制验证。
- 合并到保守大类：Ductal/Malignant→Epithelial/Ductal；Fibroblast/CAF/Stellate→Fibroblast/CAF；CD4/CD8/NK→T/NK；B/Plasma→B/Plasma；Myeloid/Monocyte/DC→Myeloid。作者细标签保留；不能将前两队列所有导管细胞视为恶性。
- 不修改作者过滤、不做表达填补或批次校正；既有作者注释尚未由本轮独立重聚类/CNV重验证。
- 原始矩阵及患者级聚合仅服务器保存，公共输出仅队列×细胞类型×基因汇总、来源哈希及映射缺口。

独立性依据：韩国Samsung/UNIST、深圳湾实验室、美国Washington University为不同原创研究；GSE242230不使用论文整合80例或重复公共队列。公开记录没有提示三者重用同批患者，但本轮不能完成受保护身份级排重。GSE278688与其SuperSeries GSE278694不算两套。

可选补充：GSE155698组织部分（排除PBMC，核对11A/B重复单位）；GSE154778原发10例（转移6例分层）；GSE202051/SCP1089为同套单核数据，未治疗与新辅助治疗分层。
