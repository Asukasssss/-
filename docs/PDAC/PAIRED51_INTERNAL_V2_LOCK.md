# PDAC 配对工作池—内部关联—细胞来源 v2（计算前固定）

采用用户本轮指定顺序，仅应用 PDAC，不改变跨癌阶段编号。已有 307 项配对统计复用；11 对中 paired P<0.05 的 51 项均为 nominal exploratory（没有 q<0.05）。全部 307 项和历史 CAMP 原效应/q 保留。

## 映射与检验单位

每一实际特征×基因只检验一次。51 项全部保留去向；精确小分子参与的人类实验注释进入 DIRECT；类别底物、身份歧义、推断证据、未确认复合体角色进入 CONDITIONAL。SAH/alpha-ketoglutarate 参与蛋白、DNA/RNA修饰的共同产物/共底物关系单列 CONDITIONAL，不能因数据库反应命中就升级成特异性代谢轴。必要复合体成员明确标为 COMPLEX_MEMBER，不称独立催化酶。无法映射保留 UNRESOLVED。数据库注释不等于重新鉴定作者峰或逐关系功能验证。

本次锁定 715 条不同关系：357 DIRECT，358 CONDITIONAL。各层分别组成固定检验族，主分析和可用性分析分别 BH，不删缺测条目（内部 P=1 占位，公开 P/q=NA）。全部候选基因做配对 RNA 和三套单细胞，不使用显著性门槛缩小基因池。

## 样本与统计

- CAMP 27T/12N 与作者 GEO 配对表按 GSM 精确连接，组织标签必须一致。21 个肿瘤有作者明确且互不重复的配对编号；主关联仅用这21个单位。6个缺作者配对编号的肿瘤不默认独立。完整 CAMP 代谢物配对为11对，配对 RNA 主背景保持同11对。作者配对表提供单位依据，未声称完成临床身份再认证。
- 来源哈希清单必须与实际四个来源路径集合精确相等且哈希逐项相同；RNA 行列标签全部非空且唯一。患者级映射及矩阵只留服务器。
- 肿瘤内部 Spearman：最少8单位，9999次双侧置换，4000次按单位重采样95%区间。可用性分析仅使用作者填补前代谢数据有值者；仍取相同作者处理尺度，不新增填补或变换。留一法输出范围、最大变化和符号变化。相同输入/方法复用 P/区间，q按新检验族另算。
- 配对 RNA：同11对，至少6完整对；与配对代谢物同一 exact signed-rank 枚举方法，零差去除、并列平均秩，10000次配对重采样 mean difference 区间。BH覆盖全部候选基因。输出升/降/相等计数。作者处理表达尺度不自动称 log2FC。
- 不复用旧27标本关联结果，因为统计单位集合已改变。旧 CAMP q、配对代谢物 q、旧关联 q、新关联 q、配对 RNA q 分开。

## 解释标签（不删除条目）

按以下顺序赋标签，同时保存全部原始指标：不可计算 R-not-evaluable；可用性可计算且符号改变或 |Δrho|>0.20 或主分析留一法符号改变为 R-sensitive；主 q<0.05、可用性同方向且以上不敏感为 R-strong；其余主 P<0.05 或 |rho|>=0.40 为 R-suggestive；其余 R-weak。可用性无法计算单独标 NEEDS_DATA，不把未检验当稳定。

## 单细胞与候选分层

复用 GSE263733、GSE278688、GSE242230 的作者肿瘤来源/细胞注释与全基因 UMI 分母。先 donor/sample×celltype 汇总 log1p(CPM) 和检出率，再供者等权。每类至少3单位、每单位至少20细胞、至少3单位检出才参与排名。canonical 精确匹配优先，否则仅唯一且不冲突的 reviewed UniProt 同义名；缺失/重复不填零。

全部候选做三队列：top、second、等权表达/检出、供者数；1000次整供者有放回抽样（同一次抽样对各细胞类别共同应用），以并列第一等分权重估计 top frequency。共同类别取三队列对该基因均合格的类别交集，至少2类才比较；分别报告全类别和共同类别一致性，避免类别缺失造成假差异。稳定来源要求三个队列全类别同一top、各top bootstrap>=0.70、检出均值>=0.05；这只是描述来源稳定，不是疾病差异验证。

A：DIRECT、R-strong、可用性可计算、RNA背景可计算、稳定来源为 Epithelial/Ductal；B：相同内部条件但稳定来源为非上皮。A/B均为探索性优先候选，不能称癌细胞特异或验证机制。D：映射条件/未解决、关联或可用性不可计算、R-sensitive、RNA背景缺测或单细胞不足/低检出；其余 C 保留生化候选（包括提示性关联或来源不一致），具体原因另列，不能把 C 全部称阴性。RNA差异显著性不是任何入场条件。

实现细化（新关联结果读取前）：D的数据不足也包括配对代谢物双方原有值子集不可评估，或该子集均值差方向与主分析相反。不会因配对RNA差异不显著归D。类别按关系逐行记录，同一基因在不同代谢物关系中可以不同。

来源术语细化（单细胞v2结果读取前，阈值不变）：B的实现为稳定的非Epithelial/Ductal来源，报告应称“组织组成/微环境背景候选”。Acinar和Endocrine仍属于胰腺上皮实质，不能因归B称为非上皮或免疫/间质；另列source_context说明。A的Epithelial/Ductal也不等于已经CNV确认恶性。

产物 candidate_pre_scRNA.tsv 和 candidate_scRNA_appended.tsv 包括全部关系和未映射特征占位。功能/外部 matched-omics 后置，明确 NOT_RUN，不以三套表达定位冒充同一关系外部复现。
