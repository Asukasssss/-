# PDAC：借鉴 BRCA 的分析规划

日期：2026-09-20
状态：建议方案；未启动新的患者级检验，未写回 GitHub。

## 1. 参考版本与规划目标

本规划依据已实际读取的 GitHub 阶段索引、分析规范和交付报告，而非仅依据历史聊天摘要。BRCA 首轮/后续基线为 `227245e3171ac3b8530835624711c1a0a69363cf`；最新功能、单细胞、稳健性及全174关系外部分析参考 `5e8cbe69063ef2c7f80731f836244c6caffe960d`。PDAC 起点为 `c508f94c80f2d68ba664a14d36bdefcd0e9f6cb9`。[B1–B6, P1–P2]

总体路线：冻结发现 → 完整直接关系池 → 肿瘤内关联、功能文献和外部来源资料并行 → 基础稳健性 → 关系级整合 → 少数明确问题的公开资源深入。

学习 BRCA 的候选覆盖、证据分层、统计复用与增量交付；不照搬其候选名单、ER模型、FUSCC队列、显著数量或阈值变化。CAMP 原论文已经研究基因—代谢物共变，因此同源重算不是独立验证或首次发现这种研究思路。[E1]

## 2. BRCA 已实施路径及其启示

- 冻结318条效应，186条原显著特征。首轮73条特征直接映射得到174条关系、117个基因；其余条件映射、未映射和未知特征保留。[B1]
- 对全174关系开展标本内关联：171条可计算，11条原关联q<0.05；不把这11条涉及的10个基因当最终候选池。全117基因另做表达背景分析。[B2]
- 全117功能资料接收包含122条证据记录；原表52个基因具有乳腺癌遗传功能表型报告分类，其中44个不在上述10个内。这是文献分类，不是52个已独立认证的靶点。[B3]
- 全候选进行可用性、逐一剔除、ER与组成代理敏感性；单细胞评估来源和来源标签重采样稳定性。代理评分不是真实细胞比例。[B4]
- 最新外部分析覆盖全174关系：133条可计算，16条FUSCC q<0.05，其中7条与CAMP同向、8条反向、1条CAMP无可比较值；不可评估和反向关系全部保留，不把16条称成功复现。[B5]
- DepMap已由用户暂缓，不重新作为PDAC前置任务。[B6]

## 3. PDAC 当前起点

保留303条冻结效应，42条原显著特征。当前为27个作者映射肿瘤标本、12个正常标本；独立患者和肿瘤正常配对尚未确认。42条显著特征全部在处理后肿瘤矩阵覆盖，16条在27个肿瘤的填补前作者数据均可用。现有两条鸟苷关联、14基因单细胞汇总和13基因CPTAC汇总属于历史起点，不是完整候选范围。[P1–P2]

GSE62452属于处理后的表达微阵列数据，不能作为RNA-seq原始counts输入计数模型。[E2]

## 4. 执行阶段

### 阶段A：基础收尾与完整映射

不重跑已验收的冻结效应。有限核对原效应方向、作者标本与患者对应、正常标本配对、输入哈希失败处理。哈希不一致时必须阻止历史统计复用。未确认身份不阻塞映射、文献和关联效应描述；任何标本级推断必须显式说明独立性假设，发现重复后改为患者单位或恰当的聚类/重复测量处理。

以全部42条特征建立一行一个去向的覆盖表；原303条保留作背景，不擅自更换发现阈值。保留原名称、原键与原q，另设标准名称、别名和身份审查字段。不能合并不同位置异构体或构型。

将关系分为：人类直接反应、直接转运、条件/近直接、上下游/邻近通路、身份待核、未找到可靠关系。直接反应和直接转运进入首轮主要关系族，其余单独保留。

可复用BRCA中同一化学实体、同一人类基因和具体反应已有的可靠来源；乳腺癌功能证据不能直接改标为PDAC功能证据。不得直接复制BRCA候选清单、统计结果或优先级。

映射完成后锁定PDAC自身的M条关系和G个基因；M、G由实际证据决定，不预设凑数。之后增加关系使用新版本。

建议交付：`feature_coverage_42.tsv`、`direct_relations_v1.tsv`、`conditional_relations_v1.tsv`、`mapping_sources.tsv`、`analysis_spec.json`。

### 阶段B：完整关系首轮关联

研究单位为同一作者映射肿瘤标本内的代谢物和基因表达，不混合肿瘤与正常来制造组间相关。

建议主分析沿用BRCA首轮的Spearman框架：作者处理矩阵，逐关系成对有限值，无新增填补；9999次双侧置换，4000次重采样形成逐项探索性区间。置换/重采样单位应与实际设计一致；独立性尚未核实的结果仅作为明确假设下的标本级探索。[B2, E3]

同时对每条关系进行作者data表可用样本子集分析，仍称“填补前可用性”，不称已核实质谱检出。记录处理后n、填补前可用n、实际联合有效n、并列值及可计算状态。

可沿用BRCA首轮n≥8作为最低可计算门槛；它不是充分样本量标准。零方差或不足门槛输出原因及NA。高缺失关系不删除，但不能仅凭填补后主分析显著就列为稳健证据；可用子集结果也可能受选择性缺失影响，不能当作自动纠偏的真值。

对相同输入、相同方法的旧统计复用rho/P/CI，不重新换seed。建议统计缓存依赖关系、实际输入和方法参数，而不是仅依赖分析标签。q根据各自检验族重新生成；相同rho/P/CI不要求不同检验族的q相同。

建议新版本统一使用预先锁定M条计划关系的BH范围，主分析和可用性分析分族；不可评估项仅在校正内部按P=1占位，公开P/q仍NA。这是选择最新BRCA外部批次的固定范围方式，不是改写BRCA旧有有效项分母的历史q。[B5]

基因肿瘤—正常表达只作为单独背景层。先确认配对结构与独立单位，再决定配对、非配对或重复测量设计；尚未确认时先提供描述性效应，不默认27与12完全独立。表达差异不是进入关系池的必要条件。

建议交付：全M关系主分析、全M关系可用性分析、G基因表达背景、可计算性/缺失原因表。所有旧CAMP q、关系q与表达q分列。

### 阶段C：基础稳健性，再做少量协变量

全关系先做逐一剔除：报告rho范围、最大变化、方向变化及有效次数；不把每次剔除当一份独立验证，不在每次剔除中寻找更显著版本。

27个肿瘤标本不直接复制BRCA的ER、多评分、多模型方案。先核对确实存在且覆盖充分的协变量；建议首轮只增加一套低维、事先指定的组成代理敏感性，确有依据再另做临床协变量模型。不要依据哪套模型显著更多来选主模型。

如使用表达推导的组成评分，核对平台适用性和标记覆盖，移除候选自身进入评分造成的循环；结果只称组成相关表达代理敏感性。每个调整模型同时给出相同完整样本集合的未调整基线，区分样本集合变化与协变量调整。

该阶段不是要求所有临床变量齐备才开展阶段B。未具备条件的模型记录NOT_EVALUABLE。

### 阶段D：全G基因功能资料，与B/C并行

每个候选至少完成一次有记录的检索和证据定位；重点来源再深入全文，不要求全候选逐篇全文审完才继续分析。

证据字段应区分：确切代谢物反应依据、PDAC中的基因遗传干预、仅表达/生存关联、其他癌种或非肿瘤模型、相反或无效结果、公开扰动资源与设计是否已核实。

逐条记录模型、细胞来源、干预方向、处理背景、表型终点、是否测代谢物/通量、是否救援及来源阅读深度。基因的肿瘤功能不等于当前代谢物—基因关系已成立；下游表达发生变化也不等于这些下游基因被直接干预。

无显著标本相关但有适用功能证据的候选继续保留。缺少文献仅表示本次检索未找到，不认定无功能。DepMap保持暂缓。

### 阶段E：现有单细胞与CPTAC扩展到全G

先复用GSE263733和GSE278688已有处理数据和注释，不从原始测序重新建一个大型单细胞项目。由历史14基因扩展到全G基因；不同设计分开，不盲目合并两队列。[P3]

每个基因报告细胞类型表达、表达细胞比例、贡献供体/标本数、两个队列来源是否一致。可增加供体逐一排除或重采样检查。差异检验按可确认生物重复的细胞类型伪批量或适当重复测量方法，不把细胞当独立患者。[E4]

历史数据没有可靠恶性标签/CNV判定时，Ductal只写导管细胞，不自动等于恶性细胞。最高表达来源一致、肿瘤正常方向一致和两队列差异显著是三个不同字段。[P3]

CPTAC从13基因扩到全G的可评估性台账。只有取得可追溯原矩阵、样本配对和批次信息时才新增计算；现有汇总不足以补出缺失基因。RNA与蛋白分别记录有效配对数、效应、q和不可评估原因，不将基因表达证据当成代谢物复现。

### 阶段F：外部资源与关系级整合

先开展一轮有边界的PDAC外部联合组学可行性核对：是否同一标本具有代谢组和表达、覆盖哪些精确特征、是否与CAMP同源、是否有可用身份和缺失信息。找到合适来源后对锁定关系全量检查可评估性，而非只挑显著候选。没有合适队列时保留NOT_AVAILABLE，不以无关癌种或只有RNA的队列冒充验证。

FUSCC是BRCA已使用的外部来源，不是现成的PDAC验证队列。研究模型、治疗背景和疾病必须逐项匹配。

从阶段A开始建立两张增量主表：一行一条代谢物—基因关系；一行一个基因的研究背景。原字段不可覆盖。关联、缺失、影响检查、文献、细胞来源、CPTAC及外部联合组学分列，不压成一个任意总分。

后续按四类工作去向组织：有较稳定关联且功能/来源背景明确；功能资料明确但当前关联不足；多来源相反需解释；身份/覆盖/设计不足待补。它们不是永久淘汰或药物靶点排名。

## 5. 三批交付顺序

1. 第一批：42特征完整映射、锁定M/G、全关系首轮关联、可用性敏感性、逐一剔除，以及全G功能初查和整合主表v1。当前验收的来源批次直接复用。
2. 第二批：全G单细胞/CPTAC可评估性与适用结果、少量预设协变量敏感性、外部联合组学覆盖表及整合主表v2。已就绪部分先交付，不等所有外部来源解决。
3. 第三批：从完整证据表选约2–4条问题明确的关系做公开扰动数据或特定模型深入；不是预定必须得到2–4个靶点。其余候选保留。每条重点关系只补最可能改变结论的一项证据，避免重复审阅同一附件。

暂不启动全量生存模型、机器学习预测模型、分子对接、空间分析、无目的单细胞重聚类或重复DepMap访问。该方案不要求新增湿实验。

## 6. 验收条件

42特征全部有去向；M/G可复算；全部计划关系有结果或明确不可评估原因；历史统计和新检验族分离；标本/患者单位准确；相同输入统计可复用；高缺失不隐去；全候选而非仅显著候选均获得基础证据定位；反向和无效结果保留；未进行与无法评估分开；阶段整合完成不等于机制已证实。
