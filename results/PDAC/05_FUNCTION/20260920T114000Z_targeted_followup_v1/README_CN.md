# PDAC 功能初查后的定向正文复核

## 本轮问题
检查摘要中的SIRT6遗传干预是否有可定位的模型、对照和救援设计。选择依据为干预设计可核查，不依据CAMP关联显著性。

## 输入与范围
PMID 41998659 / PMC13220487；定向阅读正文方法、对应结果与图例，未把下游表达变化自动计为其他基因自身干预。

## 实际结果
对87个初次零命中基因及PNP同名问题补充别名/全名检索：72个查询成功，28个对象有命中，定位51条基因—文章记录；16个对象没有合适别名可查。检索命中仍不等于功能证据，见alias_search_ledger.tsv。

正文描述PANC-1/AsPC-1的SIRT6过表达或敲低，并有MICAL2共同敲低；PANC-1皮下裸鼠实验图例报告每组n=4。SIRT6缺失增加相关表型，MICAL2共同敲低能减弱该效应。未在所读方法/结果中发现直接检验NAD+浓度或通量的实验。

## 新手解释
这支持指定模型中的SIRT6抑癌功能背景，不能证明CAMP的NAD+—SIRT6关系，也不能据候选身份就建议抑制SIRT6。

## 限制/反证
皮下免疫缺陷模型的适用范围有限；未逐份审核补充文件。正文报道不等于本项目独立复验。
