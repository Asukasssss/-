# PRAD LYPLA1：仅检出细胞的平均表达

## 本轮问题
去掉LYPLA1零表达细胞后，正常与恶性上皮的平均表达是否仍存在明显差别？

## 输入与范围
复用20260928T031839Z_lypla1_umap_v2/epithelial_summary.tsv。范围为癌组织内作者标注的正常上皮与恶性上皮，非癌旁对比。不访问或下载逐细胞数据，不重算原分析。

## 实际结果
| 指标 | 正常上皮 | 恶性上皮 |
|---|---:|---:|
| 全部细胞数 | 2200 | 3157 |
| 检出细胞数 | 453 | 2607 |
| 检出率 | 20.5909% | 82.5784% |
| 检出细胞平均log1p(CP10K) | 0.9898977474 | 0.9900816910 |

恶性减正常约0.0001839436，条件均值几乎相同。

## 新手解释
零计数对应log1p(CP10K)=0，因此“全部细胞的平均log表达 / 检出率”恰为“阳性细胞的平均log表达”。这里两组均采用细胞等权，不能拿此前患者等权均值0.224、0.815直接除以这些细胞检出率。

当前细胞等权口径下，全部细胞平均表达的差异主要体现为检出比例不同，而非阳性细胞平均log表达更强。

## 限制与反证
未检出不等于生物学上完全不表达，检出率受测序深度影响。条件均值相近不证明完整分布相同，也不是等效性检验。未计算新的P/q值；无阳性细胞间分布检验。此数值为平均log1p(CP10K)，不是平均原始计数、平均未取log的CP10K或真实倍数。

## 当前决定
描述性条件均值换算DONE；差异检验、分布检验和等效性检验NOT_RUN。

## 下一步
如需判断阳性细胞完整分布或患者层面差异，需另行读取服务器逐细胞数据并明确统计单位。
