# LYPLA1 可读性修正版 v2

## 本轮问题
v1 按表达量排序绘制，高表达点覆盖低表达和零表达点，使密集细胞群看起来同样深。用户要求更容易看出区别。

## 输入与范围
完全复用 v1 私有逐细胞表达及原始 X_umap，按精确细胞ID对齐。只展示癌组织中的作者正常/恶性上皮；altered_benign 不归入这两组。无重新归一化、聚类或差异检验。旧图保留。

## 实际结果
LYPLA1_epithelial_comparison_v2.png/.pdf：上方两个面板分别突出正常和恶性上皮，相同坐标、色标上限和点大小，使用固定种子随机绘制顺序；其他癌组织细胞为淡灰背景。下方展示患者平均表达和逐细胞表达分布。

正常上皮2,200个细胞，检出比例20.59%；恶性上皮3,157个细胞，检出比例82.58%。患者等权平均表达为0.22365和0.81488，分别覆盖12和17位每类至少20细胞的患者，与此前结果一致。两组未限制为配对患者，不是新的配对统计结果。

LYPLA1_UMAP_local_mean_v2.png/.pdf：每个六边形内计算所有细胞（包括零）的平均log1p(CP10K)，不是取最大表达。gridsize=100、mincnt=5；局部均值色标显示上限1.2，箭头表示截顶。稀疏格子不显示，不能把空白当作零表达。该图是UMAP局部均值，不是单细胞散点图或患者等权均值。

## 新手解释
随机绘图顺序避免系统性把所有高表达点放在上层。上皮分面便于对照身份；下方分布图则直接显示多数恶性上皮细胞有LYPLA1表达，而正常上皮较多为零。检出比例按当前全部细胞计算，与先前患者等权检出率不同。

## 限制与反证
绘图改进不等于统计显著。当前没有新P值；细胞检出率受测序深度影响。UMAP局部均值可能混合邻近细胞类型，不据此定义新群体或推断轨迹。平均log表达比值不能解释为真实倍数。

## 当前决定
图形修正DONE，保留所有v1表达值；差异检验NOT_RUN。
