# PRAD参考BRCA主线：第一轮整合交付

问题：PRAD代谢差异能否连接到直接基因、同肿瘤RNA关联与细胞表达背景？

输入与范围：91个作者肿瘤case，43对肿瘤/正常；全361个作者保留特征。原351项冻结结果与旧5条关系/10条统计原样保留。

实际结果：

|环节|结果|
|---|---|
|代谢物主配对|361项可评估；69项P<0.05；9项q<0.05|
|作者可用值敏感性|344项可评估；66项P<0.05；9项q<0.05|
|CAPT一致36对敏感性|361项可评估；57项P<0.05；2项q<0.05|
|直接映射|48项代谢物；161条关系；101个基因；21项待身份/证据补充|
|肿瘤内关联|161条均可评估；18条名义P<0.05，0条q<0.05|
|配对RNA|101基因可评估；35个P<0.05；21个q<0.05|
|单细胞来源|一项24供者肿瘤研究；91个基因可评价主要来源；第二研究未完成|

新手解释：PRAD有代谢和RNA差异，但本轮没有代谢物—RNA关系通过其完整检验族的FDR校正。因此不能把RNA差异或单细胞高表达补成已验证的调控轴。全部候选均保留供比较，而不是只交显著项。

限制与反证：7对CAPT字段不一致；361个特征中10个化学键碰撞已分峰保留；作者可用值掩码不等于确认检出；关联属同队列事后选择；单细胞只有一研究，癌旁是同研究参考；CELLxGENE网页GEO外链冲突在单细胞阶段记录；没有功能验证。21项未充分映射不是阴性。

当前决定：第一轮作为可讨论的探索性证据包。21个RNA FDR基因提供表达背景，不自动升级治疗靶点。未完成项：21特征映射补证、第二独立单细胞研究、独立患者关系验证；功能深入不是本轮来源主线强制项。

下一步：优先补可改变判断的独立关系证据与第二研究可靠注释；不改变当前阈值、不删除未显著候选、不追加机制分析。
