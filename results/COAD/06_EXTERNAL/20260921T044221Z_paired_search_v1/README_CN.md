# COAD 配套数据搜索与取得情况

## 本轮问题
寻找独立人原发结直肠癌组织、同标本代谢物与RNA/蛋白配套数据，用于原39条关系的外部复核。

## 输入与范围
原39关系、35基因、23代谢特征及9/21/5分层不变。本批有限检索新增4个入口，接回2个原取数入口；不是全面系统综述。不重读Chen两份已完成核查的DOCX。

## 实际结果
最具体的新入口是Integral-Omics（2025，DOI 10.1021/acs.analchem.4c04421）：作者报告6名CRC患者的同份组织连续提取多组学，出版商附件目录明确列出Table S4“Colorectal cancer multiomics data”XLSX。官方BioProject PRJCA026610列出12个组织BioSample，GSA入口HRA007600。尚未取得S4，不能确认其实际数值列、35基因/23代谢物覆盖和对应关系。ACS正文及一次按其常用命名规则尝试的附件URL均返回403；猜测URL不作为已核实的S4下载地址。bioRxiv公开附件访问也受阻；浏览器尝试超时。旧预印本提到的PXD054560在本轮ProteomeCentral探测返回“Dataset not yet accessible”，不据此断言数据不存在。

第二条是2026年PRRX2血管侵犯预印本（SSRN 7030030）：原始摘要报告116例转录组、84例代谢组、154例微生物组，67例用于匹配整合。67是论文报告数，不是本项目已核实可分析人数；未取得处理后矩阵、标本对应与数据声明。SSRN正文访问受阻。

ATF6（2025）提供MTBLS7387与GSE247122，但人CRC代谢组和所述小鼠RNA实验不能构成人同标本配套验证。MassIVE MSV000096806为人CRC代谢组原始谱入口；元数据已取回服务器，尚未确认配套RNA/蛋白，且不下载原始谱。数据库通用Proteomics标签不代表已测配套蛋白。

Chen/Li仍保留作者取数路线，本轮没有发信。新增处理后矩阵0、新增患者检验0；这不是候选关系的阴性结果。

## 新手解释
找到同时测过多种组学的研究，是第一步；拿到可逐标本对齐的数值表，才具备检验关系的输入。Integral-Omics的S4比单纯论文线索更具体，但仍须取得并检查。即使可用，也至多是6人的小样本复核，不能把6个肿瘤和6个癌旁合成12个独立肿瘤患者。

## 限制/反证
新线索的结肠/直肠分布、治疗、实际化学身份、缺失和技术重复均未审核；没有认证队列独立性或全特征覆盖。网页检索索引可读不代表服务器能下载。检索有限，不宣称没有其他合适数据。

## 当前决定
06_EXTERNAL保持PARTIAL；配套关系验证NOT_RUN。优先取得Integral-Omics S4与方法/临床补充；PRRX2作为较大样本备选。其他候选、历史P/q和9/21/5均保留。

## 下一步
取得S4后只在server165读取，先核对患者/组织/技术重复和矩阵尺度，生成23特征与35基因覆盖摘要；先锁定可评估关系再做统计。RNA和蛋白独立分层。若只有差异清单或均值，不启动关联。D13需实际数据入口和完整处理矩阵，不能用通路相似性替代。

## 复现命令
服务器新运行目录建立独占`.running`后，复制并运行`python3 probe_paired_sources_v1.py <server_run_dir>`。脚本只探测6个公开元数据入口，响应留服务器，公开retrieval_log.json仅含请求状态/哈希/路径。文献筛查由dataset_inventory.tsv和source_manifest.tsv记录；不宣称该HTTP脚本能复现人工检索或分析患者数据。
