# COAD：补充单细胞来源筛选与元数据实读

## 本轮问题
为全部35个既有基因寻找能补充Lee/Pelka的细胞来源资料。保持原39条关系与9/21/5安排；本轮不新增差异筛选。

## 输入与范围
核对GSE200997原论文、GEO和作者仓库，GSE166555及GSE164522的GEO原始登记；实际在server165下载并读取GSE200997 GEO注释。已有两研究结果直接复用。

## 实际结果
优先候选GSE200997：原研究为Rush医院16名未治疗患者，10x5′；方法为DAPI排除死细胞、活单细胞分选，未描述CD45选择。实际注释49,859细胞、23样本：肿瘤31,586细胞/16样本，正常18,273细胞/7样本。GEO摘要49,589与实际文件不一致，按实际文件记录；论文说明8个正常中1个质控排除，解释最终7个。该注释只有样本、组织、部位、MSI、CMS预测等列，没有细胞类型，不能直接输出细胞来源。

作者仓库固定提交39e855925a8a2806e2ef0500927a2bb16b243be4包含CRC_Metadata.zip以及celltypes.zip.001/.002/.003，已核实文件清单和解压说明。服务器尝试取得CRC_Metadata.zip超时（35秒），部分下载不能使用；celltypes分卷尚未下载或检查。GEO另提供完整UMI矩阵，本轮未下载，35基因覆盖尚未计算。

第二个全谱系候选GSE166555：原登记12患者、25标本，10x3′v2，公开130.3MB计数TAR和77.2MB元数据；有同患者多标本，不能当25独立患者。暂未取得矩阵/注释，治疗和分选细节仍需原方法确认。

GSE164522作为免疫补充：公开原发肿瘤矩阵及metadata，但CD45富集，101是多个组织区室的标本总数。只在原发肿瘤免疫层内分析，不能用于上皮/基质来源或全组织细胞比例。肥大细胞覆盖尚未实读。

## 新手解释
找到可下载矩阵与适用研究只是入口。要说某基因来自哪类细胞，必须把表达矩阵接到真实的患者和细胞类型标签。CMS分型不是细胞类型；文件名叫annotation也不保证包含这些标签。

## 限制/反证
本轮没有新的基因表达结果、相关或P/q。不能保证新增队列解决HDC肥大细胞低覆盖。Khaliq论文还分析Lee/Pelka等历史队列，只纳入其自行采集部分作为新增研究。综合图谱/重复网站不额外计数独立验证；患者来源仍需逐队列核实。来源定位不证明代谢关系或酶活。

GSE200997优先，GSE166555备用，GSE164522仅免疫补充。来源发现完成；新队列细胞类型接入PARTIAL，表达分析NOT_RUN。Lee/Pelka35基因既有批次保持完成，不重做。
