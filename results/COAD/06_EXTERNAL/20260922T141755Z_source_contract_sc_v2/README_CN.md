# COAD全候选表达来源：Lee与Uhlitz

## 本轮问题

按照45c6ae9固定执行合同，完成当前直接、条件性、未解决及历史保留候选的表达来源去向。单细胞止于表达来源，不做机制或肿瘤—正常差异检验。

## 输入与范围

811个稳定基因ID记录，含526个当前直接池基因。三个身份暂挂记录（两个CBS同名ID及一个缺符号ID）不强行赋表达。808个可按现有符号规则检索的记录，优先精确符号，只有已核实ADSS2旧名ADSS例外；缺项不是零。

Lee/GSE132465使用已取得原始UMI矩阵与作者注释；Uhlitz/GSE166555使用25份作者计数矩阵与明确case_id/GEO患者对应。排除论文复用其他研究和类器官作为新增研究。旧35基因的CPM结果不覆盖。

新尺度为每细胞完整基因库CP10K后log1p，先供者×细胞类别求均值，再对供者等权平均。每供者类别至少20细胞，每类别至少3供者；至少两个类别可评估且最高类别平均检出率≥1%才显示定位。1000次供者联合重采样保留缺类，最高并列分摊权重；保持率≥80%仅为描述性稳定。

NNMT：Lee基质与Uhlitz成纤维背景，原类别保持率均1。AQP9：Lee髓系与Uhlitz单核背景。HDC：Uhlitz肥大细胞保持率1、平均检出约61.0%；Lee暂不可定位。SLC38A3：两研究均因最高类别检出不足1%而不显示确定来源。

GSTA4在Uhlitz新尺度下最高为成纤维，保持率约59.7%；BCAT2最高为周细胞，保持率71.6%，不能以机械最高值宣布唯一来源。与历史患者伪合并CPM中位数的差异涉及汇总尺度，不能解释为新独立矛盾或覆盖旧结果。

## 新手解释

表达来源用于选择细胞背景。某类表达最高不意味着其贡献最多组织RNA、产生对应代谢物或承担唯一作用。患者等权与把所有细胞混在一起的均值不同。

## 限制/反证

宽类别是明确登记的近似对应，不是原亚型完全一致。Uhlitz纸面/GEO的10x版本差异保留，未新增清除环境RNA；使用已准入计数。跨研究独立性依据原始招募来源，不是逐人身份交叉认证。Lee全库分母复用原核验缓存并核对矩阵哈希，Uhlitz全库UMI逐细胞核对作者nCount_RNA。

两项已准入元数据均无可用UMAP坐标；不编造嵌入。没有经确认的患者临床分型，Uhlitz细胞表达CMS标签不替代临床分型。缺失模块在报告中保留。功能文献只沿用历史索引，不新增811基因功能判断。
