# COAD：Khaliq新增队列全35基因细胞来源

## 本轮问题
用Khaliq2022自行采集的GSE200997补充全35基因细胞来源。复用既定汇总标准，不重算Lee/Pelka，不改原39条关系、974候选或9/21/5。

## 输入与范围
作者仓库固定提交39e855925a8a2806e2ef0500927a2bb16b243be4的celltypes三分卷，GEO注释，以及论文Table S1/S2。全部矩阵、逐细胞和逐患者数据只存server165。

实际分析42,696个细胞、23个标本，覆盖16个肿瘤标本和7个正常标本。作者Table S2明确将对应标签列为Patient，23个标签逐一匹配Table S1、S2和GEO；按组织分别汇总，不按编号后缀推断跨组织配对。论文为Rush医院16名未治疗患者，10x5′、DAPI活单细胞分选，未描述CD45选择。GEO和作者分卷属于同一研究，论文复用的其他队列不纳入此批。

## 实际结果
全部35基因保留，其中32个在所有六个作者区室具有可用独立条目。逐基因/区室的缺失或映射状态见gene_availability.tsv。GSTT2、SLC6A17、UPP2缺少条目；核对六区室的23,828个特征集合完全相同，所查SLC6A17/UPP2别名也未命中（symbol_check.json）。GSTT2B虽存在，但不替代GSTT2。

## 新手解释
不同患者的细胞数不一样，先在每位患者中汇总，再让患者等权。即便某区室平均排名最高，检出率很低时也只代表弱表达线索。零UMI与条目缺失分别处理，不添加伪计数。完整分布和原作者亚群在by_gene目录；数字亚群保留原编号，不自行命名。

## 限制/反证
GEO共49,859细胞，本次作者区室导出只覆盖42,696，另7,163细胞未包含，按组织保留覆盖记录；不把它们填成0或强行分配类型。所有结果限于作者公开的区室导出。

作者没有单列肥大细胞标签，本批不能作为HDC肥大细胞定位的独立验证，也不能据此排除该来源。Tcells区室实际含NK和ILC，保持这一范围；上皮标签不自动等于已确认恶性细胞。成纤维细胞、内皮分别保留，不等同于历史研究的宽基质类群。

来源定位不验证对应代谢物—基因关系，不改变原CAMP关联FDR结果，也不决定抑制或增强基因。未新增P/q或肿瘤—正常差异检验。

## 当前决定
本批全35基因在已取得六区室内的来源表达计算DONE；未注释细胞和肥大细胞问题继续保留NOT_EVALUABLE。原39条、9/21/5不变。新增队列用于选择合适细胞模型，不变成新靶点排名。

## 下一步
将本批完整分布与Lee/Pelka逐项对照，首先解释覆盖、亚群范围和技术差异。HDC如需肥大细胞补充，应先核查其他队列原注释及患者覆盖；不将本批缺标签当生物学阴性。配套代谢验证仍是单独任务。
