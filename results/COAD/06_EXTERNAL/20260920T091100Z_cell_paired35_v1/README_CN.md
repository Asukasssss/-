# COAD 全35基因患者配对表达与39关系整合

## 本轮问题

结束来源总览批次，转向同一原注释细胞类型中同一患者的肿瘤—正常表达变化，并将新证据接回原39条代谢物—RNA关系。范围固定为已核查35基因，不扩展为全部458计划基因。

## 输入与范围

复用server165上Lee与Pelka已有患者级伪合并计数、检出细胞数、总UMI与细胞数，精确合并v1的HDC/GSTA4和v2新增基因。两个版本的所有患者分层键、细胞数、总UMI均逐一一致；四份输入SHA256锁定后未变化。未使用公开中位数倒推患者值，也未重读原始矩阵。

按研究×处理/富集×技术×原注释层级×细胞类型，用原患者ID匹配肿瘤与正常；同一分层内原有同患者标本聚合继续沿用。一侧缺该类型不补0，未配对者及覆盖不足均单列计数。全部766个观察到的细胞分层乘35基因，共26,810行；缺基因、无配对和低覆盖不删除。

未CD45富集的所有大谱系为主分析，其余原始细分类型和富集组为探索性次分析。每侧至少20细胞、至少6对患者才检验；3–5对仅描述，少于3对抑制表达数值。没有按最高CPM标签筛选类型。方法和范围在查看配对效应前提交并核对远端a3e5547197437502fbfcd442523c118505743173。

患者伪合并CPM=基因UMI/该患者该类型全部基因UMI×百万；报告患者内T−N差值中位数及至少95%覆盖的次序统计区间。精确双侧符号检验只检查非零差值中上升/下降的方向是否平衡；零差值保留在效应估计中，检验分母单列。全零p=1。每研究分别对主分析、次分析全部可检验组合进行BH；技术分层纳入同研究同层级检验族，不挑显著者另校正。无新转换、伪计数、插补或批次校正。

主分析共700个计划组合，374个可检验。Lee有5类（每类8–10对），Pelka未富集v2有6类（每类14–28对）；Pelka v3最多5对，不进入推断。GSTT2无独立条目，全35名单仍保留。Lee主分析17个显著组合涉及15个基因，Pelka34个涉及24个基因；它们不是独立验证的代谢关系数。

较清楚的跨研究同向变化包括AQP9、ENO2在髓系上升，ASPA在基质下降，B4GALT2、ICMT在基质上升，均在各研究主检验族q<0.05。但两个研究的原始细胞注释不是逐一等价，不能把宽谱系直接当作完全相同亚型。Pelka上皮中UCKL1上升（28对，差值中位数7.5834 CPM，q=8.815527e-06），PRMT7下降（28对，−4.4705 CPM，q约0.002295）；这仍是基因级表达，不是PRMT7剪接事件或尿苷机制验证。

## 新手解释

来源回答“在哪些细胞中表达”；配对比较回答“同一患者同类被采样细胞在肿瘤组织中是否变化”。本轮新增q属于外部单细胞表达方向检验，不是原CAMP q，也不是患者代谢物—RNA关联q。不能用它覆盖原M1/M2关联全检验族无FDR支持的结论。

CPM差值是相对表达的差，不是倍数，也不是酶活或通量。统计检验评价非零差值方向，中位效应评价全部达标配对的差值分布；存在大量零差值时，两者可能不同，UPP2就是实例。区间不是多重校正后的同时置信区间。

## 限制/反证

这是一项保守的患者层面方向一致性分析，不是edgeR/DESeq2负二项计数模型的差异表达结果。符号检验不利用差值大小，功效有限；六对的门槛只保证有限95%中位数区间及最小双侧P可小于0.05，不是足够功效的保证。相对CPM仍可能受总转录组成变化影响。

正常参考来自本研究的正常/邻近组织，不代表独立健康人群。宽细胞类群内部亚状态变化、处理偏倚和技术因素不能全部消除；上皮不自动等于恶性细胞。富集与未富集分开，细分类型与上层谱系有嵌套关系，不能重复计为独立生物学验证。只有被采样且配对达标的患者进入每个组合，不能外推所有患者。

B4GALT2、BPGM等获得表达变化支持也不自动解除功能暂挂。没有新的配套代谢物测量、代谢救援或空间验证，不能称已验证代谢轴。原来源总览和本批表达变化来自相同外部队列，不互相算作独立研究。

## 当前决定

全35配对可评估性/表达效应及39关系回接批次DONE；外部代谢关系验证和最终整合阶段仍PARTIAL。974条、39条及9/21/5安排不变。功能干预、患者关联、外部表达变化三类证据保持独立含义，不合成未经验证的靶点评分。

## 下一步

以39关系综合表逐条判断适用细胞模型和缺失的代谢物介导证据；有表达变化不等于有代谢关系。对宽谱系信号使用已生成的细分结果审查覆盖和方向，不按最小P选亚型。HDC空间定位、PRMT7变体作为单独问题；GSTT2需要独立可用测量，UPP2/SLC38A3等继续标记低检出限制。

## 复现命令

在server165新独占目录复制run_cell_paired35_v1.py、cell_origin_v1.py和锁定配置，建立.running；旧输入按input_hashes.json校验。

```bash
python3 test_cell_paired35_v1.py
python3 run_cell_paired35_v1.py --out "$NEW_RUN_DIR" --spec analysis_spec.json --audit-only
python3 run_cell_paired35_v1.py --out "$NEW_RUN_DIR" --spec analysis_spec.json --lock-commit a3e5547197437502fbfcd442523c118505743173
# 只导出public/汇总到仓库本批目录后：
python code/coad/integrate_cell_paired35_v1.py
python tools/check_repository.py
```

两项服务器合成测试涵盖精确P、反转、全零/部分零差值、区间和BH。实际检验包含26,810行唯一键、覆盖阈值、缺基因与公开限制、区间边界、独立BH重算及39原字段不变。软件版本见validation.json。

方法依据：[原始单细胞重复单位研究](https://doi.org/10.1038/s41467-021-25960-2)说明生物学重复的重要性；本轮精确方向检验使用[SciPy binomtest](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.binomtest.html)，不声称该论文验证了本轮具体检验设计。
