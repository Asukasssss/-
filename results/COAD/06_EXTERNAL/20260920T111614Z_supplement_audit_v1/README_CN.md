# COAD：Chen 2025补充文件服务器核查

## 本轮问题

服务器恢复后，实际检查上一批未能读取的两份候选补充DOCX，确认能否支持39条关系的独立同标本代谢物—RNA/蛋白验证。

## 输入与范围

承接`20260920T105400Z_relation39_feasibility_v1`中的D01。论文入口：https://link.springer.com/article/10.1186/s12943-025-02359-x 。两份源文件只下载到server165的`data/candidates/coad_relation39_20260920/`，未下载到本机或GitHub。新建独占服务器运行目录，复用原下载脚本并将OUT明确设置为本次路径；没有覆盖上一批记录。

检查OOXML包完整性、文件哈希、表格结构、表题/表头、嵌入对象及外部链接。本轮不从图像读取患者值，不从汇总图逆推配对矩阵，不进行患者统计。

## 实际结果

|---|---|---|
|MOESM1，7,133,583字节|7个补充图标签、8个媒体对象；0张DOCX表格|无嵌入式电子表格或外部数据链接；图像不能替代已标注的完整个体数值矩阵|

两份文件均通过ZIP/OOXML读取和SHA256记录；均未发现嵌入式电子表格或外部链接。两份文件中没有可直接用于预定全关系分析的机器可读组学矩阵，不能据此推断论文没有产生数据或其他位置绝无数据。没有新增统计或已可运行的独立验证关系。

## 新手解释

本次解决了“文件读不到”，也确认了“文件中是否有下一步所需的数据”。现在缺少的是同一标本的实际组学数值与对应关系，不再是服务器登录。临床资料和补充图有用，但不能代替每个样本的代谢物与基因测量。

## 限制/反证

这是两份指定补充文件的结构核查，不是完整论文所有数据入口的穷尽搜索，也不是图像逐点数值提取。未核实23个代谢物/35个基因的实际外部覆盖、精确配对或最终独立患者数。不把缺文件当作阴性结果。原CAMP/M0/M1/M2、表达统计、39关系及9/21/5均未改变。旧批次ACCESS_BLOCKED是当时真实状态，保留历史，由本批追加恢复记录。
