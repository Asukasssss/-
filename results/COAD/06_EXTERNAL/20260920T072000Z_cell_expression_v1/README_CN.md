# COAD：HDC/GSTA4 患者等权细胞表达定位

## 本轮问题

按已上传的表达前规则，实际计算 HDC/GSTA4 的细胞来源描述。当前已完成 Pelka；Lee 完整计数读取中。协变量及候选名单不重算。

## 输入与范围

表达前锁定提交09498b9。Pelka作者版371,223细胞、62患者、43,078个原始基因特征；读取全量766,487,382条稀疏计数记录。五种处理、正常/肿瘤、10x v2/v3及原注释层级分别计算；详细覆盖在前一批。Lee矩阵已完整下载并通过gzip校验，数值汇总尚未完成。

HDC的相对集中定位是肥大细胞，不能概括为所有髓系细胞。GSTA4在原注释的基质及上皮群中更明显，基质细分包含内皮和成纤维细胞；不能简单归为髓系来源。原Mast、Granulo、Macro等标签保留，不把肥大细胞与其他粒细胞标签混合。CD45富集单独表内展示，不与未分选汇总合并。

## 新手解释

这些结果回答“外部队列中，哪些细胞可检测到较多这两个基因的RNA”。CPM是每位患者每类细胞的目标UMI总和除以该类全基因UMI总和，再乘一百万；没有填补或伪计数。先对每位患者计算，再等权取中位数。它不能换算成该类细胞贡献了整个组织多少代谢物。

## 限制/反证

RNA检出受深度与解离影响，零中位数不等于每个患者都无表达，也不排除低丰度细胞的功能作用。技术层分开不等于两项独立研究。Pelka基质回收有限；没有计算组织细胞比例、空间共定位或CAMP样本的细胞组成调整。不能据此验证HDC—组胺或GSTA4—谷胱甘肽因果轴。Lee肿瘤肥大细胞仅3个、2名患者，无法提供稳健的该来源复核。

## 当前决定

HDC下一步优先检验肥大细胞相关来源假设；GSTA4分开考虑上皮与基质/宿主背景。原974/39和9/21/5不变；M1/M2均无FDR支持的原结论不变。少于3患者不公开表达数值，低于5达标患者标记低覆盖。全批无新假设检验，无P/q。
