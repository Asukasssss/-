# COAD更适合的单细胞资料筛选

## 本轮问题
针对当前全811稳定ID的来源缺项，寻找供者、取材和细分注释更清楚的独立资料。不是追求显著性更好看，也不替换已收口统计。
## 输入与范围
以d551e38为已交付基线；核对GEO/EGA/Zenodo原始登记、作者公开代码及论文方法。10项入口分层；有限检索，不宣称穷尽。
## 实际结果
优先准入MUI_Innsbruck：作者自采12人CRC，独立h5ad约2.2GB已确认HEAD 200及登记MD5。作者代码记录naive治疗、患者/标本/取材字段和raw counts，富集字段naive的实验含义仍需核实。包含直肠位置映射，不能称12例纯COAD。完整细胞类型标签可能需从最终atlas回接，不能假定输入h5ad自带最终标签。
CRC整合atlas用于注释参考与抽取其他研究，不能整包当新队列；模型文件仅高变基因，不适合完整候选覆盖。优先原始全基因计数，不能以整合值推断表达量。
GSE245552和GSE231559作为独立原发子集候选；当前均混合转移/重复或其他组织，必须先解开元数据。GSE188711为小规模左右侧补充。GSE164522限CD45+免疫背景，不能比较全谱系。EGA56人线索含32治疗前，当前受控FASTQ，不属于现成处理后数据。
2025年64人/100标本论文的方法实际使用Pelka GSE178341，不计新队列。GSE221575仅2原发患者；GSE201348包含核测序和大量非癌标本，降低优先级。
## 新手解释
“更合适”首先是问题匹配和字段可核实，不等于总细胞更多或候选更显著。本轮首选是新队列准入优先级，还没有证明实际覆盖优于Lee/Uhlitz。

本轮未下载患者/细胞矩阵、未计算新来源或P/q。稀有细胞覆盖、811ID完整性和MUI的最终注释待实际读文件。未绕过访问控制、未提交数据申请。MUI论文全文403，网站本机证书不匹配；Zenodo及作者代码可读。
