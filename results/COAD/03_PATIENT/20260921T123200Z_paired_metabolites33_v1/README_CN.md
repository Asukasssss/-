# COAD：33位患者肿瘤—本人正常代谢物配对结果

## 本轮问题

按用户示例，逐项报告有多少患者的肿瘤代谢物高于、低于、等于本人的正常组织，并按同向对数分组。结果入口：[中文分组表及159项完整明细](PAIRED_COUNTS_CN.md)；[中文TSV](paired_counts_CN.tsv)；[浏览器阅读版](PAIRED_COUNTS_CN.html)。本轮是新增配对代谢物分析，不覆盖冻结CAMP效应、原q或既有肿瘤内部关联。

## 输入与范围

- 冻结COAD全159项特征，未按旧73项显著或39条代谢物—基因关系缩小检验范围。两张作者分组表均160行，其共有159项正好是本轮范围；只在肿瘤表出现的N6-acetyllysine、只在正常表出现的Indole-3-acetamide不属于本轮冻结159项。
- 按既有GEO明确individual，匹配33位Ⅰ–Ⅳ期患者的肿瘤及正常：33对、66个标本。未使用腺瘤或0期，未按排序推断配对。患者级映射及数值保留server165。
- 作者工作簿 `PreprocessedData_COAD.xlsx` 的T/N表分别精确等于同一 `data_imputed` 表的对应子集。填补前 `data` 中有限值保持不变。没有新增归一化、填补或批次修正。
- [CAMP原始论文](https://www.nature.com/articles/s42255-023-00817-8)及[作者预处理代码固定版本](https://github.com/reznik-lab/pancancer-metabolomics/tree/92ad028d9b225b1e2c42e41700a265f45103d731)：COAD使用正常参考的PQN、对数变换、最小值填补，随后按作者映射筛选分组；未将T/N分别中心化。`1_PreprocessMetabo.R`、`2_ImputeMetabo.R`、`3_FilterMetabo.R`源文件及哈希保存本次服务器运行目录。对数底数未认证，因此不报告倍数变化。
- `analysis_spec.json` 在任何配对差值计算前写入。主分析与填补前双侧可用子集分别固定159个计划检验，不可评估项仅BH内部按P=1占位，公开P/q为NA。每种分析最少8对。
- 双侧Wilcoxon符号秩检验：`zero_method=wilcox, method=approx, correction=False`；全零差值P=1；采用并列秩修正的正态近似。效应为全部可用配对差值的中位数；4000次患者对bootstrap百分位95%区间为逐项描述区间。人数统计保留所有相等配对。P值不是对同向人数比例做的二项检验。

77项有完整33对填补前数值，82项至少有一对涉及作者填补。94项主分析显著中92项在可用子集仍显著；2-Deoxyglucose 6-phosphate（15对，子集q=0.07299）和5-hydroxylysine（14对，子集q=0.67418）未保留校正支持。子集另有新增支持，不与主分析累计为独立证据。

子集2,3-diphosphoglycerate只有6对、Cyclohexylamine只有3对，未进行推断但保留人数。异柠檬酸子集9对，触发SciPy小样本正态近似提示；保留预定方法与结果，解释时注明近似限制。

## 新手解释

“32/33升高”表示32人的肿瘤值高于本人正常值；其余1人可能降低或相等，以明细为准。图中†表示至少一对涉及作者填补，不能理解为33对全部实测。这里的“有值”是作者处理数据可用，不是原始质谱检出认证。

94项是本轮33对肿瘤—正常的代谢差异结果，与冻结CAMP原73项不是同一统计版本，也与原39条肿瘤内部代谢物—RNA相关不是同一个问题。代谢物差异显著不能推出某个基因导致这种差异。

## 限制/反证

PQN参考和作者填补影响解释；描述的是作者相对归一化对数尺度，不是绝对组织浓度或通量。新配对q不替代原q。并列/零差值及小样本近似保留；Wilcoxon的分布位置解释依赖差值分布条件。样本身份依据作者GEO注释，未做遗传身份认证。中文翻译仅为显示，不把混合特征、来源缩写或Disulfiram等名称注释升级为化学身份确认。没有任何新的RNA关联、功能干预或外部队列验证。
