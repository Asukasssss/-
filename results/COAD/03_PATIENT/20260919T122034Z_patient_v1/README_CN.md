# COAD 第一轮患者关联与配对 RNA：COAD_patient_v1

## 本轮问题

从 COAD 冻结效应独立建立的生化候选，在患者肿瘤内部是否呈现 RNA—代谢物关联？对应基因的 RNA 在同一患者的肿瘤与正常组织间是否有差异？两者分别检验，不能互相代替。

## 输入与范围

完整目录 974 条；预先固定有反应注释支持且无当前特定身份暂挂的 674 条，其中 652 条有 RNA。RNA 家族为 458 个基因，其中 446 个有对应行。其他 300 条候选及 22 条家族内 RNA 缺项保留明确状态，不补零。

GEO 明确 individual 与作者映射核对后，37 个 Tumor 对应不同患者；含 3 腺瘤、1 个 0 期，故主分析为 I–IV 期 33 人，配对 RNA 使用其各自正常组织。全部 37 人另作敏感性分析。身份核验来自提交者注释，不是基因型指纹。[GEO](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE89076)、[原研究](https://pubmed.ncbi.nlm.nih.gov/28847964/)。

肿瘤内部 Spearman，平均秩处理并列值，双侧 9999 次置换加一法 P，4000 次患者 bootstrap 的逐项 95% 区间。配对 RNA 使用作者尺度上的中位差、双侧 Wilcoxon 符号秩正态近似及配对 bootstrap。BH 分别按主分析、全部37、可用性子集、配对RNA的可计算家族进行；计划数/实际数同时记录。无额外转换、填补或批次校正。方法、种子规则、输入哈希与软件版本见 analysis_spec.json；方案在数值计算前已提交至 `10485806bf4dedd071c571d009614541e8c660d3`。

## 实际结果

| 分析 | 计划检验 | 可计算 | 实际 n | 新 q<0.05 |
|---|---:|---:|---|---:|
| I–IV期肿瘤内关联 | 674 | 652 | 33 | 0 |
| 全部作者Tumor关联 | 674 | 652 | 37 | 0 |
| 作者数据可用性子集（本批初始版本） | 674 | 652 | 11–33 | 0 |
| 同患者肿瘤减正常的RNA差异 | 458 | 446 | 33对 | 314 |

314 个 RNA 差异中，146 个中位差为正、168 个为负。主关联最小 q=0.326；39 条未经多重校正的 P<0.05 不称显著发现。全部37最小 q=0.1956。

652 条主关联均完成逐一剔除患者检查；174 条在至少一次剔除后改变相关符号，最大 |rho变化|=0.12844。这是全家族描述，不是新显著性门槛。

本批 availability33.tsv 是保留的首次数值记录，其 437 条 n=33 项与主分析输入完全相同，却使用了另一随机种子。此问题在读取关联结果前由样本可用性核对发现，另按 AGENTS 的相同输入复用要求交付 `results/COAD/04_ROBUSTNESS/20260919T122940Z_availability_reuse_v2/`：437 条直接复用主统计，215 条样本减少项保留原计算，统一重算该敏感性家族 BH。**当前可用性结果应读 v2，不以本批随机波动解释稳健性。**主分析、全部37及RNA结果不变。

## 新手解释

RNA差异问“这个基因在肿瘤里是否比同人的正常组织高/低”；关联问“不同患者中，这个基因RNA更高时，代谢物是否也系统性更高/低”。前者显著、后者不显著可以同时成立。652 条均未达到本轮 q 阈值，不代表生化关系不存在，也不代表整个项目没有候选；不能只保留39条名义P较小的关系重算q。

## 限制/反证

样本较小且跨分期/部位；年龄、性别、分期、部位调整本批 NOT_RUN，纯度及技术批次尚未核实。RNA与代谢物丰度不等于酶活、运输速率或通量；生化反应注释与复合体角色仍需逐项复核。代谢特征由同一CAMP队列的原差异筛选，本轮是探索性关联，不是外部独立验证。bootstrap区间为逐项区间，未做家族校正；区间不跨零也不能替代BH判断。配对Wilcoxon检验的是差值分布的符号秩位置，在解释为位置差时依赖分布条件，不是一般意义的中位数检验。

作者 data 表的有限值只定义数据可用性，未证实为原始检测掩码。身份暂挂仍未解除；不存在匹配RNA行不等于不表达。原 CAMP q、新 RNA q、新关联 q 分开保存。

## 当前决定

主分析及配对RNA范围 DONE，基础稳健性部分完成；协变量/功能/外部证据未完成。完整候选继续保留，下一轮依据适用功能证据与患者证据共同判断，不把本次关联显著作为功能取证门槛。原冻结效应与q逐值保持不变。
