# COAD：三研究细胞背景接回39条关系与Integral分层准入

## 本轮问题
收口Khaliq细胞来源批次，将其覆盖和解释接回既有39条关系。记录论文更正范围，主线转回Integral同标本代谢关系；不默认增加第四个表达队列。

## 输入与范围
复用Lee/Pelka来源总览、Khaliq35基因总览及六区室完整肿瘤汇总、原39条综合表和Integral准入结果。三项研究共四个技术展示层，Pelka v2/v3不额外计数独立研究。

## 实际结果
新增gene35_source_context.tsv和relations39_source_context.tsv。后者只追加source3_字段，39行顺序及全部130个原字段逐字符串一致，原文件SHA256不变。没有重算来源表达、患者相关或P/q。

- AQP9、SLC15A3、SLC29A3：宽髓系最高中位表达位置较一致。
- BCAT2、UCKL1：上皮线索较一致；不升级为恶性细胞特异性。
- GSTA4、NNMT：宽基质背景与Khaliq成纤维细胞线索相容；不视为相同亚型复现。
- SLC6A6、PRMT7、KMT5A：原研究或技术之间的差异完整保留，不作多数票判断。
- HDC：Khaliq缺肥大细胞标签，不能复核该来源，也不是阴性反证。
- ASPA、ENTPD3、PGAM2、SLC38A3：Khaliq达标区室中位数均0，不等于全部细胞均0。
- GSTT2、SLC6A17、UPP2：当前作者区室导出缺条目，与低表达分开；不扩大成全部原始资料不可测。

其余基因也逐项保留四个展示层的原标签、最高值、检出率及有效覆盖。Khaliq六区室的覆盖和中位表达一并接回，不能把“16个肿瘤标本”写成每类细胞均有16位达标患者。成纤维为7、髓系为11、上皮为15；内皮仅4而未进入最高值比较。7163个未纳入作者分卷细胞仍保留覆盖限制。

核实并补记[2022年7月13日更正](https://link.springer.com/article/10.1186/s13059-022-02724-9)：仅说明附加文件1的Fig. S5错误并已替换。该通知没有指明本批计数矩阵或Table S1/S2被更正；不推断矩阵有错，不据此重算，也不把更正当独立数据验证。

Integral按RNA与蛋白分别登记在integral_layer_gates.tsv：30条RNA、11条蛋白的结构/数值检查与精确排列程序核验均直接复用。两层source_status仍为NEEDS_REVIEW、association_status仍为NOT_RUN。任一层具备自己的来源说明及共同代谢组说明后，可独立锁定并运行，不必等待另一层。

本轮针对165已有methods.txt的归一化、填补、数据分析和存储入口字段定向搜索，命中S23/S24/S26/S27的处理方法，未找到S4字段级导出/归一化/填补说明。官方Figshare方法与S4元数据均为v1，custom_fields为空、关联指向原论文，没有提供额外字段字典；ACS正文直接读取返回403，不能把这次有限检索写成穷尽全部正文。没有重拆S4/S8或重新做覆盖审计，也没有新获取患者矩阵。

## 新手解释
“在哪类细胞中表达较高”用于选择模型，不能替代“同一肿瘤中该代谢物与基因是否关联”。三研究背景接回后，原39条关系的统计证据等级没有升级。

## 限制/反证
比较限于每项研究已注释、覆盖达标的类群；原细胞标签不完全等价，CPM最高值不是特异性或显著性。23个Khaliq标本不等于23名独立患者；不新增跨组织配对推断。

Integral两层仍共同缺少B_metabolome跨样本归一化与导出前缺失/填补说明；RNA另缺RSEM具体字段、归一化和零值语义，蛋白另缺DIA-NN导出字段、归一化及NA语义。完整蛋白数值不证明从未填补，软件名称或默认设置也不能认证实际导出字段。未添加任意标准化，未发送邮件。
