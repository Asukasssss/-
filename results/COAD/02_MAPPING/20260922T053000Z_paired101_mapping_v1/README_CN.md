# COAD：101项配对代谢物工作池的直接关系映射v1

[101项中文去向总览](FEATURE_OVERVIEW_CN.md)｜[891条主池](main_relations.tsv)｜[526基因覆盖台账](gene_coverage526.tsv)

## 本轮问题

落实用户的新路线：配对代谢物发现→直接关系映射→CAMP肿瘤内部关联与配对RNA→全候选单细胞来源→有针对性的外部配套组学验证。本批完成101项的首轮结构化映射及新旧覆盖对照，不再以旧39条关系、35基因限制入口。既有七阶段目录编号保留。

## 输入与范围

使用既有33对主分析全159项，其中101项配对P<0.05（94项q<0.05，7项名义支持）。72项与旧73项入口重叠，29项新增；胞苷是旧入口中本次未进入101项的唯一特征，旧记录单列保留。

只使用COAD既有证据缓存及本批新增公开数据库查询，不读取BRCA候选。复用KEGG、reviewed人类UniProt、Rhea快照；补充29项化合物/反应与81个尚未被缓存覆盖的候选基因查询，并按hydroxyglutarate、hydroxybutyrate、sebacic、nonanoate、piperidine、hydroxypentanoate、CNP、malonate补查可能缺少KEGG路径的记录。检索词仅定位记录，不直接生成关系。

主池要求：人类GeneID明确；精确小分子ChEBI或Rhea官方pH形态出现在催化反应中，或同一分子明确出现在转运反应in/out两侧；没有当前身份暂挂；并非只有蛋白/核酸修饰或信号GTPase循环背景。KEGG同一路径、宽泛EC或关键词本身均不足以进入主池。原始名称与ID没有被替换。反应书写左右侧不推断组织内净反应方向。

必要复合体成员单列角色，不能把SDHB、SUCLG1、FARSB等称为独立完成反应的酶。普通氨酰tRNA合成反应中的游离氨基酸直接底物关系保留；蛋白/核酸残基修饰背景按当前工作规则放条件层。数据库注释支持不等于COAD功能证明。

## 新手解释

这里把“理论上有直接处理关系”与“患者中是否相关”分开。891条是下一轮需要统一检查的关系集合，526是去重基因数；不能将每个基因都称为代谢物特异靶点。candidate_pre_scRNA.tsv已接回配对代谢物统计、旧关联和旧RNA背景，并明确标记新版患者统计NOT_RUN；它是下一步的输入表，不是宣称内部关联已经完成。

## 限制/反证

1. 本轮是覆盖全部101项的限定数据库注释检索，不是穷尽全部人类代谢文献。结构化无命中不证明没有直接关系。N-乙酰甲硫氨酸、甘氨酰甘氨酸、1-甲基腺苷、2′-AMP、2-羟基丁酸、哌啶本轮未找到满足规则的直接支持，全部保留。
2. 丝氨酸原KEGG C00065指L型，而[原HMDB0003406条目](https://hmdb.ca/metabolites/HMDB0003406)指D型，保留两种假设并暂挂。2-羟基戊二酸未确定R/S；glutarate的C5-DC标签、3-methylhistidine的位置命名、混合糖磷酸信号均保留问题。药物/暴露样名称不得因抑制作用被映射为生成或消耗关系。
3. 异柠檬酸和眼酸有关系线索，但本版精确ChEBI条件未通过，不用近似实体或宽化学类替代。旧identity_review.json中的历史检索字段保留来源语义，当前去向以feature_workpool101.tsv和results.tsv为准。
4. 复用的UniProt实验注释码仅代表数据库记录的既有证据，不代表本轮阅读了所有原始实验，也不代表在COAD成立。蛋白表达不等于活性或通量。
5. 本批没有计算新的患者P/q、配对RNA或单细胞表达，没有取得新外部矩阵。配对代谢物值、原CAMP值、旧患者值分列保存。

## 当前决定

本批范围DONE：101项全部有去向，159项完整保留；锁定891条直接关系为下一轮v1待检验集合，526个基因进入相应RNA背景与后续单细胞覆盖台账。378条条件关系、197条未解决关系和旧池外记录均保留，不删除也不偷偷纳入主检验族。整体生物学映射仍有上述待核查问题。

独立核验PASS：159项原值与配对字段逐字符串一致；1466条键唯一；891条主池均能通过支持表连接到精确化学实体证据；特征级数量全部重计一致；7个正向边界例子、6个条件边界例子及复合体角色核对通过。结果文件SHA256见validation.json及analysis_spec.json。

## 下一步
