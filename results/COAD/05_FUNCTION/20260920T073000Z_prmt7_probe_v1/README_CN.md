# COAD：PRMT7 实际探针与参考转录本核查

## 本轮问题

将原“未取得探针”推进到实际序列核对，判断本平台探针是否提供参考转录本区分能力；不重算现有患者关联。

## 输入与范围

GSE89076 实际样本 SOFT 的平台为 GPL16699。读取官方平台原始表，得到 PRMT7 的两个60nt探针 A_23_P77437（ID6500）和 A_23_P77430（ID12281）。仅对平台注释涉及的两个明确版本 RefSeq NM_019023.5、NM_001184824.4 作完整60nt正向及反向互补精确匹配。这不是全基因组脱靶评估。

## 实际结果

|探针|NM_019023.5起点|NM_001184824.4起点|
|---|---:|---:|
|A_23_P77437|1617|1332|
|A_23_P77430|2313|2028|

坐标为转录本1-based、匹配长度60nt。两个探针均完整匹配两个参考转录本，反向互补均无精确匹配。平台获取及本项序列比较 DONE。

## 新手解释

这两个探针都落在这两个参考转录本共有的序列上，不能靠它们分别定量这两个参考转录本。现有按基因符号合并的矩阵更不能反推出 V2/V1 或 PSI。

## 限制/反证

论文 V1/V2 与这两个 RefSeq 的对应未确认，数据库“variant 1/2”不等于论文标签。沿用已接收的 GRCh37 可变剪接受体 AA_exon16/PRMT7_AA_16.1 事件说明，不把它改成整个外显子16跳过。本轮 ScienceDirect 返回403，EuropePMC 未提供全文或补充序列，尚未取得论文构建、引物及区分接头。不能把当前参考转录本结果扩大为整个平台绝无任何变体分辨可能，更不能据此否定论文机制。

## 当前决定

保留已有 PRMT7 基因级关联及分期敏感性解释；变体定量 NOT_EVALUABLE。事件特异探针对照 NEEDS_REVIEW。974/39及9/21/5不变，无新增P/q。

## 下一步

取得论文特异构建或接头序列并核对注释版本，再完成事件匹配；若需变体定量，先确认具有分辨能力的测量平台。已有参考序列精确匹配无需重复。
