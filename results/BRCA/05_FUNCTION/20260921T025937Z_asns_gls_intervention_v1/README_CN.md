# BRCA ASNS/GLS：公开干预资源与首批Asns敲低RNA分析

## 本轮问题
停止增加同一批FUSCC患者模型，优先寻找ASNS或GLS自身干预、对照及重复明确的公开处理后数据。先运行已具备条件的ASNS资源，GLS资源单独保留未决状态。

## 输入与范围
GEO有界检索返回46个ASNS关键词系列、7个GLS/乳腺关键词系列，全部返回摘要已在服务器缓存。这不是系统穷尽检索。找到同一2018年ASNS研究的三个鼠4T1-T数据集。GSE104967作者计数矩阵中第二对照Sample 2全列为0，不能按两有效对照检验；本轮未运行该数据差异分析，也未推断零列是生物学结果。

本轮实际运行GSE104966：24个作者标注生物学重复，每组4个，原发瘤来源与肺转移来源分别建模，各有shRenilla、shAsns-1、shAsns-2。细胞经历体内生长、分离、6TG筛选和再培养，不等于未经处理的原组织。列归属使用作者明确编号说明及GEO样本标题；第21列说明缺字母A，由该组明确的GEO标题确认，不根据数值猜测。动物身份及独立性未另行核验，重复字母不作为配对依据。

仅在server165下载作者处理后整数计数，未下载FASTQ或原始质谱。本轮四项比较与过滤、校正范围在差异结果产生前冻结。

## 实际结果
1. 两条构建在两种来源细胞中均显示Asns RNA显著下降。

|来源|构建|Asns log2FC|模型估计相对对照RNA倍数|全四比较BH q|
|---|---|---:|---:|---:|
|原发瘤来源再培养|shAsns-1|-2.244|0.211|2.52e-7|
|原发瘤来源再培养|shAsns-2|-1.050|0.483|0.000356|
|肺转移来源再培养|shAsns-1|-2.119|0.230|7.00e-8|
|肺转移来源再培养|shAsns-2|-1.613|0.327|8.31e-7|

2. Gls、Gls2、Glul在四项比较中均未通过全量联合校正。Gls log2FC为+0.074至+0.231，点估计小幅上升；Gls2为+0.021至+0.522；Glul为-0.067至-0.257。不能将这些趋势写成已证明的代偿。原发瘤来源shAsns-1的Gls2全量q=0.05368，也不为过0.05另换校正范围。

3. 全转录组：原发瘤来源检验12264基因，两构建分别3199和3719个通过全四比较q<0.05；两者共同显著且同向2621个。肺来源检验12359基因，分别153和247个通过，共同显著同向49个。两构建效应秩相关分别0.892、0.509。共49246项基因×对比做一次BH；另保留每对比q，仅供追溯，不替代主q。差异基因数不是新靶点数，也不能凭两来源显著数不同证明效应存在显著来源差异。

所有23478个原基因的过滤去向、四份完整差异表、16行预定节点结果、QC与热图均已交付。没有仅发布显著行。低表达基因不标成阴性。

## 新手解释
此前患者数据是在问“不同肿瘤中，基因表达和谷氨酰胺是否一起变化”。本轮换了一种证据：作者真实敲低了Asns，我们重新分析其公开RNA数据。

Asns RNA下降说明这批测量捕捉到了靶基因转录降低；其他很多RNA也有变化。然而Gls等三个节点基因没有明确的全量统计支持，因此目前不能说“ASNS降低后GLS一定补偿升高”。未显著也不等于已经证明完全不变。图中蓝色表示RNA降低、红色表示升高，数值是log2倍数，星号使用49246项主检验家族q。

## 限制/反证
只有RNA计数，没有本轮可分析的谷氨酰胺/谷氨酸/天冬酰胺测量、酶活或通量。不能用RNA差异或通路分数替代这些终点。鼠细胞结果不直接验证人FUSCC的关系；两构建共享对照、属于同一论文，不能算两个独立队列。RNA模型倍数不是酶活下降比例。

GSE104966经过体内选择和再培养，处理构建可伴随选择/细胞状态差异；没有动物配对与批次元数据可供额外调整。本轮未作不同来源效应的交互检验。库总计数8.48M至38.05M，全部保留，TMM及计数模型处理文库规模，不按结果排样本。每组4个是作者生物学重复标签，不是本轮新验证4只独立动物。

差异采用edgeR4.0.16、limma3.58.1，分来源三组模型，TMM、filterByExpr(min.count10/min.total.count15)、robust估计及QL F检验。不是重现原论文全部分析流程。效应对应置信区间未另估计，表中NA并说明，不虚构。BH值由Python独立核对通过；未做第二套算法择优。

## 当前决定
ASNS方向已获得首批实际公开干预RNA再分析；支持限定于该鼠模型转录反应。GLS仍保留患者支持与已发表功能依据，本轮尚无GLS自身干预矩阵结果。

GSE104964是Asns已敲低细胞的天冬酰胺供给比较，保留作为营养背景数据，不能当成新的Asns对照敲低。GSE263696是谷氨酰胺缺乏适应株RNA，GSE26370是营养剥夺，均不能冒充GLS敲低。GSE107109为患者原发与转移比较。各资源详见resource_decisions.tsv。全117候选和既有患者统计保持不变。

## 下一步

## 复现命令
在server165新运行目录中准备source/public和独占锁，复制脚本，依次运行：
```
python3 brca_prepare_asns_intervention_v1.py --root RUN_ROOT
Rscript brca_asns_intervention_v1.R RUN_ROOT
python3 brca_summarize_asns_intervention_v1.py --root RUN_ROOT
```
R包安装到RUN_ROOT/Rlib，版本及依赖见R_sessionInfo.txt（Bioconductor3.18对应R4.3；edgeR4.0.16）。原始处理矩阵和完整样本映射只在server165。source_manifest.tsv保存源URL与哈希。运行摘要表results.tsv遵循公共统计字段前缀；四份完整*_all_DE.tsv保留edgeR原生列，logFC对应effect，PValue对应p_value，q_global4对应本轮主q，author_n_treated/control对应n/n_reference；共同参数从analysis_spec.json读取。
