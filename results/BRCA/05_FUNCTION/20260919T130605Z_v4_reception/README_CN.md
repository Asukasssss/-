## 新手解释

这次新增的是“别人改变过哪些基因，在哪种模型里看到了什么”，而不是我们又算出一批新的显著性。

原来的10个来自患者标本中的代谢物—RNA关联；52个来自文献类别，两者回答不同问题。二者不重叠并不矛盾：例如某基因只在耐药、免疫细胞或骨转移背景中有作用，原发肿瘤整体RNA相关未必能表现出来。44个不在原10个内，说明继续研究全部117个候选有意义；它们仍是别人研究过的对象，不是本项目新发现的44个功能基因。

24个“优先核查”表示下一项工作具体、可能改变判断。它既可能包含有较好依据的候选，也可能包含方向矛盾的候选；不是“最好的24个靶点”。

## 限制／反证

### 重点解释补充

- **PMM2**：所读摘要支持ESR1 Y537S表达背景下的作用及部分药物重新敏感；未确认CAMP有该背景，不能推广到所有乳腺癌。[原研究](https://pubmed.ncbi.nlm.nih.gov/38266771/)
- **UPP1**：原文的遗传删除是全身Upp1缺失，肺转移发生比例降低，但原发瘤负担和临床终点时间未改变。作者明确指出尚未以中性粒细胞特异敲除完成整条机制的直接验证。因此可以保留免疫/转移研究方向，不能写成已证明中性粒细胞特异因果链或普遍抑制原发瘤。[原研究结果与讨论](https://link.springer.com/article/10.1038/s44319-025-00520-7)
- **PRODH2**：原研究包含过表达/敲除和骨转移模型，适用重点是骨微环境；原发CAMP标本关联不能替代骨转移证据。[原研究](https://pubmed.ncbi.nlm.nih.gov/40749014/)
- **ETNK1**：2026研究中降低ETNK1会逆转部分环磷酰胺效应，2024摘要中的构建/方向又有不一致。保持方向待核定，不能直接建议抑制。[2026研究](https://pubmed.ncbi.nlm.nih.gov/42003071/)、[2024研究](https://pubmed.ncbi.nlm.nih.gov/38694857/)
- **LDHA**：保留特定稳定敲低克隆的无效结果；它不能代表所有急性干预模型，也不能因存在正向研究而删掉。[原研究](https://pubmed.ncbi.nlm.nih.gov/28314283/)
