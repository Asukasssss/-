### 对原判断有实际影响的内容

**PMM2（S086）**：2024研究在ESR1 Y537S表达背景中报告PMM2耗竭使ERα/FOXA1及增殖改变，并使部分药物重新产生作用。这是特定突变和治疗背景，不自动适用未确认ESR1状态的CAMP样本。来源：https://pubmed.ncbi.nlm.nih.gov/38266771/

**UPP1（S113）**：2025乳腺肿瘤模型研究将中性粒细胞UPP1、尿嘧啶、肺细胞外基质和转移联系起来。基因缺失/抑制有相应终点，值得核查免疫细胞来源；不能因bulk肿瘤关联不显著而判无功能，也不能把已发表机制写成新发现。来源：https://pubmed.ncbi.nlm.nih.gov/40702342/

**PRODH2（S091）**：2025原始研究涉及羟脯氨酸与骨微环境、基因过表达/敲除和骨转移终点。优先判断有没有适合复用的骨转移数据，而不是以原发瘤中相关不显著淘汰。来源：https://pubmed.ncbi.nlm.nih.gov/40749014/

**ETNK1（S031/S032）**：旧研究摘要干预方向表述不一致；2026研究中ETNK1降低逆转CTX诱导的自噬/铁死亡及存活影响。因此目前不能概括成“抑制ETNK1抗乳腺癌”，应先核实干预构建与治疗条件。来源：https://pubmed.ncbi.nlm.nih.gov/38694857/ 和 https://pubmed.ncbi.nlm.nih.gov/42003071/

**LDHA（S057/S058）**：既有抑制方向报告，也有MDA-MB-231稳定敲低至极低表达后乳酸、ATP和存活没有改变的原始研究。需区分急性干预、稳定克隆适应和LDHB背景；不删除无效结果。来源：https://www.nature.com/articles/srep21735 和 https://pubmed.ncbi.nlm.nih.gov/28314283/

**LDHB、FDFT1、FH、NAMPT等**：不同细胞类型、模型或终点下存在分歧，已分别列出；不能统称“建议抑制”。这些记录的模型适用性应优先核查。

**GPCPD1（S039/S047/S115）**：已有模型功能与代谢读出，适合做有依据的参照候选。但特定ER阴性/HER2阳性研究不是所有BRCA患者的机制证明，也未证明CAMP相关由GPC介导肿瘤表型。来源分别见2016、2023、2024记录。GPI、ASNS、NNMT等同样应区分现有功能基础与真正新增问题。

**HPRT1（S050）**：本轮核查到乳腺癌/MCF10A中的siRNA研究及公开转录组GSE149768线索；所读材料支持分子层面干预，不把它写成已证明抑瘤。对没有实验条件的项目，可先核查此类公开扰动数据是否适用，而不新增患者相关性轮次。

## 新手解释

“有功能报告”是指别人真的在相应模型中改变过基因并观察终点，不是文献只提到这个名字。不同终点须分开：增殖减少、迁移减少、治疗增敏、细胞组成改变，不是同一个结论。

“优先核查”意味着下一项资料核定最可能改变判断，可能是证据矛盾或模型尚不明确；不意味着它比所有保留候选更可靠。成熟对象可作为参照，不必无限追加同样的分析。暂挂仅暂停追加投入，保留所有统计和来源。

请先看Excel的“说明与汇总”，再看“117基因比较”，按记录ID转到“功能文献明细”。每条研究均列模型、干预、结果、代谢测量、限制和来源。完整TSV用于程序回接。

## 限制／反证

本轮是覆盖全117的定向检索和有界取证，不是全部文献的穷尽性系统综述。多数记录核查到PubMed摘要、关键正文或图注，实际深度逐项标注；部分仍需模型/方法核定，个别仅保留旧版来源或一手访问受阻线索。未对全部来源完成逐图质量审计和撤稿/更正核查。题名栏可能为内容概述，文献身份以URL/PMID/DOI为准。

患者身份独立性仍未核实。ER之外完整亚型、纯度和批次未充分控制；作者工作表可用性不是原始检出掩码。同数据的v2/v3不是独立复现。基因层功能不能自动推广为该基因所有代谢关系的介导证据。

FUSCC全318条匹配详细表不在本次实际读取的仓库资料内；不将历史摘要伪装成本轮新增外部验证。CPTAC旧10基因组织/plex混杂对比不参与正向加分。DepMap维持NOT_RUN/DEFERRED_BY_USER，数值与模型数留空。
