# BRCA：PYCR1的CAF蛋白、RNA与翻译终点核对

## 本轮问题
实际读取Kay2022研究的Supplementary Data4及图1、图3、扩展图3源文件，区分RNA、胶原蛋白和同位素/翻译测量。确认能否进行敲低比较，同时查GSE220931的ENA记录。

## 输入与范围
4份作者XLSX、原论文页面与ENA九条run元数据留server165；GitHub只提供汇总、脚本、参数及审计。复用已有研究，不是独立验证。无原始质谱或FASTQ重处理，无新CAMP计算。完整117候选及历史数值不变。

## 实际结果
### Supplementary Data4的说明与文件不一致
网页描述称含cCAF siCtl/siPYCR1，但实际唯一工作表13行、4条肽段序列；6个测量列全部是shCTL(12C)或shCTL(13C)，各3列，且标为log2强度。未发现PYCR1敲低列。13行涉及位点，不能当13个独立重复；NaN不能填0。因此此表不能计算PYCR1敲低后标记脯氨酸进入胶原的变化，也不能把强度直接称合成速率。此前仅据附件说明认为能做敲低比较，需要修正。

### 可明确读取的图3数值
以下是作者预处理尺度上的“敲低组均值/对照组均值”，不是新P值或患者关联：

|模型、面板|测量|对照均值设为100%后的值|重复|
|---|---|---:|---|
|pCAF2，Fig3i|敲低后的ECM COL6A1蛋白/Ponceau|50.6%|3个作者实验块|
|pCAF2，Fig3i|敲低并补充脯氨酸后的同一蛋白测量|78.0%|3个作者实验块|
|cCAF，Fig3n|敲低后的COL1A1 RNA/18S|98.6%|每组3个作者技术重复均值|
|pCAF2，Fig3o|敲低后的COL1A1 RNA/Actin|82.9%|每组3个作者技术重复均值|

Fig3i的9个蛋白/上样参照比值均与底层强度独立复算一致。qPCR使用作者Average列，没有把每个孔当生物重复。本次未重新评估全部qPCR计算规则或实验独立性。

Fig3p有22个作者列出的ECM基因及三个条件汇总。22个敲低值均高于对照，补脯氨酸后均低于敲低值；但没有按3个生物重复展开的数据，且是作者选出的基因集合，不能当22个独立实验做检验或称所有ECM基因都如此。

### 保留未决问题
Fig3g的三行写作siPYCR1、siPYCR2、siPYCR3，不擅自改为同一敲低的重复1/2/3。Fig3h文件有4个实验块，而图注写n=3，不挑选其中3个。上述面板本次未作新效应检验。
ENA对GSE220931提供9条run，标题与GEO标题一致，包括shP2_2/3；但这是相同提交的关联元数据，不是独立的构建身份验证，仍未解决GEO genotype的shP3/shP4冲突、附件单位及生物重复设计。没有新增程序P/q。

## 新手解释
这批数据支持把PYCR1放在“脯氨酸供应与胶原蛋白制造”背景下理解；RNA数量不一定同步降低。但COL6A1蛋白与COL1A1 RNA是不同胶原成员，以上比例不能相减得到翻译贡献，也不能证明在我们的CAMP样本中由脯氨酸介导。补脯氨酸后信号提高是原研究的支持性结果，不等于普遍适用的治疗结论。

## 限制/反证
只做有界描述性再提取，无新增P/q、区间或等效性检验。RNA均值接近对照不等于已证明无变化。原实验已发表、不同面板并非一条完整同样本测量链；不能与本项目单细胞结果合并成独立机制验证。网页附件描述错误风险、标签和重复数矛盾已逐项保留，未全盘否定论文，也未默认全部源数据已通过核验。

## 当前决定
PYCR1保留限定癌细胞/CAF专题，不提升为整个BRCA第一主线。明确撤回“癌细胞胶原RNA评分可验证CAF胶原机制”的设计含义。历史E2F/胶原单细胞结果仍保留为转录关联，调整依据是模型/终点匹配而非显著性。GPCPD1外部未复现、GPI外部缺项及其余候选安排不变。

## 下一步
现有CAF研究足以明确终点区别，继续重算同一论文不会构成新的独立证据。若推进癌细胞E2F干预问题，先解决GSE220931单位及重复设计，第二构建身份单独暂挂；不默认重跑FASTQ，不为了显著性新增通路。未联系作者。
