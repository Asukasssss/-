# BRCA 单细胞数据选择：先做完整117基因的细胞来源定位

## 本轮问题

找到可以实际接入的乳腺癌单细胞资源，比较117个基因在哪些细胞中表达，再判断哪些候选适合癌细胞、免疫或基质研究。数据选择不按候选显著性缩减范围。

## 输入与范围

候选仍为117个基因。检索原始论文、作者数据说明、GEO、CELLxGENE和作者代码仓库，完成6项资源的用途分层。实际访问10个入口，9个返回成功状态，Pal注释对象的Figshare入口返回403。

本轮仅获取公开资源元数据和不含患者测量的基因字典。表达矩阵尚未下载，未完成细胞注释连接、患者计数或表达检验。后续矩阵与完整样本映射仍放server165。

Pal公开基因字典有33,538行，117个候选符号全部存在。结果见 [gene_dictionary_coverage_117.tsv](gene_dictionary_coverage_117.tsv)。这只是“这些基因在测量字典里”，不是“117个都有可用表达”，更不是全部117个都在癌细胞表达。细胞检出率和患者覆盖均明确留为NOT_RUN/NA。

## 新手解释

首批使用Wu，是为了给全部117个基因确定细胞背景；第二套Pal用于看这种来源判断是否能在另一个研究中重现。两个数据库分别分析后比较，不先混成一个大矩阵。

正常乳腺参考回答“非肿瘤组织中的哪些细胞也表达这个基因”，不能单凭低表达宣布安全。空间数据留给已有具体细胞邻近问题的候选，且必须先核查基因面板。

## 限制／反证

- **标本和患者要分开。** Pal的GEO页面写52位患者，2022作者数据说明写55位；均有69份表达谱。当前不替作者选择一个数字，也不以69充当独立患者数。正式分析从作者明确映射核对，重复取样或不同分选部分不能当独立人。
- **作者对象可能重复包含同一细胞。** Pal有多个分组整合对象；Reed全局、细胞分群和Integrated HBCA也可能交叠，不能把它们相加作为更大独立队列。
- **版本和计数口径有差别。** Reed论文报告801,360个QC细胞，当前全局资产列803,283；SCP1039门户显示的细胞数也不应直接当作待下载GEO矩阵列数。实际读取后保存版本与统计。
- **细胞覆盖必须测。** 人类图谱是否充分捕获中性粒细胞尚未验证。少见或未捕获不能证明UPP1无表达；小鼠来源只能作相应模型背景。
- **分选和批次会影响解释。** 上皮富集与全组织样本不能直接比较天然细胞比例；不能把一个研究的肿瘤与另一个研究的正常混合后，将批次差异认作肿瘤特异性。
- **表达不是代谢机制。** 单细胞RNA没有直接测量CAMP代谢物、酶活或通量；它也不能仅靠表达数据确认PMM2对应的ESR1突变背景或PRODH2的骨转移机制。
- **访问成功不等于完整下载通过。** 本轮检查文件头/元数据，尚未对完整矩阵做校验或注释连接。Pal Figshare403单独记录，不阻塞Wu。

## 当前决定

采用“Wu主分析 → Pal跨研究复核 → Reed非肿瘤参考”的顺序。保留小鼠免疫和靶向空间资源作为具体问题的补充。GSE276609不新增计入独立人类队列。

阶段DONE只指本轮资源筛选与入口检查完成；单细胞表达计算尚未开始。完整117个基因都进入后续可评估性表，未测到或无法比较的项保留原因。

## 下一步

先在server165新目录取得Wu处理包，连接作者细胞注释与标本信息，核对基因标识、恶性细胞标签和独立患者单位。优先复用作者注释，不以重新聚类作为前置条件。

首批交付应包含：117基因×细胞类型的表达/检出情况、每项实际患者覆盖、亚型覆盖、作者恶性标签与不可评估原因。按患者汇总，避免让细胞多的单个患者主导结果。先做来源描述；需要正式比较时另行固定模型、比较范围和多重检验族。

## 复现命令

在仓库根目录指定不存在的新输出目录：

```bash
python code/brca_sc_resource_probe_v1.py --repo-root . --out /absolute/path/to/new_resource_probe
```

脚本只读取元数据、一个基因字典并对大文件发送HEAD，不下载表达矩阵。访问状态可能随时间改变；保存本轮快照供追溯。生物学用途是人工判断，不能由HTTP200自动推出。
