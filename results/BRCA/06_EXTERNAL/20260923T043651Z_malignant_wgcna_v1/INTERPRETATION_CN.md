# 对现有结果的判断

本轮能够定位LYPLA1的共表达背景，但没有把它确立为稳定的跨队列核心基因。

1. Wu中LYPLA1进入pink模块：213个基因，kME=0.4974，模块内第127名。17个有效模块之外有2003/6000个基因未分配（grey），不把这些基因算进有效模块。
2. 模块的主要富集背景是ATP合成、氧化磷酸化、呼吸链，也有囊泡/溶酶体相关条目。48个GO条目通过全63512项联合BH，它们存在重叠，不是48项独立机制。细胞脂质分解q=0.3369，脂肪酸β氧化q=0.3784，因此不能把该模块称为脂质特异模块。
3. Pal固定模块的LYPLA1 kME约0.4982，与Wu相近；但整个pink模块的供者层面保留Zsummary=1.3205，低于常用探索性参考线2。当前没有获得该模块整体保留的明确支持。两者不矛盾：一个基因与概括表达的相关可以保留，而其他成员之间的结构不稳定。
4. 固定模块、逐次去除一个Wu供者后，排除LYPLA1自身的kME范围为0.4009～0.5553。它说明这项相关没有被某一位供者单独决定，不能证明每次重新建网都会把LYPLA1分入同一模块。
5. 原有LYPLA1—LPC16:0患者关联和配对RNA结果继续保留。本轮不足以用“WGCNA hub”增强靶点推荐，也不据此否定其全部研究价值。
