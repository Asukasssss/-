# BRCA 117基因单细胞分析：首批Wu完成，另外两套运行中

## 本轮问题
117个代谢相关基因主要在哪些细胞中表达？全117保留，不只分析旧10个。

## 输入与范围
Wu2021 / GSE176078，CELLxGENE固定版本22a27631；100064细胞、26个作者供者标签。所有源数据与逐供者测量留server165。

## 实际结果
117/117基因字典匹配；完成9大细胞类的供者等权表达和检出比例。11 ER+、5 HER2+、10 TNBC供者标签；21未治疗、5已治疗，亚型和治疗状态分别汇总。Pal与Reed仍运行，本批不宣称三套完成。

## 新手解释
表达量先在同一个供者的同类细胞中求平均，再对供者求平均，避免一个人细胞多就影响过大。检出比例指这类细胞中测到该基因RNA的比例；它不是肿瘤发生率。effect是平均log1p每万计数，不是浓度倍数。

## 限制/反证
每供者细胞类至少20个细胞；公开表达汇总至少3个供者标签。未达标保留NOT_EVALUABLE，不视为不表达。没有新增P/q、没有代谢物测量、没有证明酶活或因果。癌细胞注释复用作者判定。作者供者ID不等于本轮完成基因型身份核验。

## 当前决定
Wu数值结果完成；全117进入跨研究比较。Pal仅选后续图谱中的pal_2021来源，不纳入其中Wu重复细胞。Reed作为非肿瘤参考，不做跨队列肿瘤—正常显著性比较。

## 下一步
完成Pal和Reed汇总、跨研究细胞来源比较、细胞覆盖敏感性后更新同一运行交付。
