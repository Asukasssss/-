# BRCA：117基因单细胞来源分析 v1

## 本轮问题
CAMP关联到的117个基因，主要在癌细胞、免疫细胞还是基质细胞中表达？不同研究是否给出相似细胞来源？正常乳腺参考中是否也能看到表达？

## 实际结果

- 三套均完成全117的细胞类表达、检出比例、来源供者覆盖；保留不可评估行，不缩成旧10基因。
- Wu与Pal共有8个可比较大类。99个基因达到技术可解释条件，82个在共有类别中的最高表达类别一致；细胞类别表达排序相关的中位数为0.881。这是**8类细胞排序的相关**，不是CAMP患者代谢物—RNA相关，也不是新靶点验证数量。
- 18个基因在至少一套肿瘤数据的检出信号过少，仍保留全部数值和原功能证据。PRODH2在其中。最低可解释规则为至少5个共有类别且两研究各至少一个类别的供者平均检出比例达到1%；该技术解释保护规则是在观察到稀疏基因后加入，不是预注册显著性门槛。
- 117基因原比较表的109列逐字符串保留，只追加单细胞结果。没有重算CAMP、RNA或患者关联的P/q；本轮新增假设检验为0。
- 完成每供者每类至少20细胞改为50细胞的覆盖敏感性，以及Wu未治疗子集比较。

以上GPI、ASNS、PMM2、NNMT、GPCPD1、PNP、UPP1的最高类别在各研究20→50细胞要求下均保持。Reed中GPCPD1也偏髓系、NNMT偏成纤维、PNP及UPP1偏内皮；ASNS、PMM2等也在非肿瘤细胞中表达，因此不能据此声称癌细胞专属或已证明正常组织安全。

## 新手解释
**这一步是在定位RNA信号来自哪里。**一块肿瘤组织包含癌细胞、免疫细胞、血管和成纤维细胞。之前整体RNA高，可能是某类细胞多，也可能是该类细胞本身表达高；本轮提供细胞来源线索。

表达值先用每个细胞全部保留基因的总计数标准化到每万，再取自然对数log1p；不能只用117基因作分母。先算每供者每类细胞的平均，再对供者等权平均；检出比例是测到该基因RNA的细胞比例。effect不是浓度倍数，检出比例不是患者患病概率。

每个供者每类至少20个细胞，每个公开表达汇总至少3个来源供者标签。覆盖不足的类别不填0。主来源只是可测类别中相对最高，不等于仅在该类表达。没有测到RNA也不等于没有蛋白或生物作用。

先读gene117_cell_source_CN.tsv的“一句话解读”，再查原细胞类表中的n、effect和mean_detection_fraction；celltype_labels_CN.tsv提供中文名称。

图key_genes_cell_source.png和all117_cell_source.png是研究内、同一基因跨细胞类别的标准化热图。红表示相对较高、蓝表示相对较低；灰表示没有合适数据或该基因检出过少。颜色不是显著性，不能跨不同基因或队列当绝对量比较。

## 限制/反证
1. 只测RNA，没有单细胞代谢物，没有证明基因作用由CAMP代谢物介导，也没有测酶活或通量。
2. Pal使用后续再处理注释，原作者完整注释受阻；细胞来源独立不等于处理方法完全独立。来源标签中类似0029的不同命名不按数字后缀擅自合并或宣称独立，未新增患者水平推断检验。
3. 三研究细胞捕获、富集、测序深度和注释不同。正常参考单列，未做混杂的跨队列肿瘤—正常差异检验。每类供者覆盖不同，最高均值不是严格的同供者配对细胞类对照。
4. 低检出不作为功能淘汰条件；稀少细胞尤其不能被当成真实缺失。没有合适的中性粒细胞覆盖，不评价UPP1中性粒细胞特异机制。
5. 当前正常参考不是药物安全性实验。没有追加DepMap、预后、空间或代谢因果推断。

## 当前决定
本轮三套**可用导出范围内**的117基因细胞来源分析完成；原版Pal全范围仍ACCESS_BLOCKED，见scope_status.tsv。全117继续保留，依据细胞背景解释已有患者关联和功能文献，不以单细胞最高类别机械筛掉基因。

## 下一步
优先对已有患者证据和功能证据中的矛盾补最小分析：癌细胞背景中的GPI/ASNS/PMM2；基质背景中的NNMT；免疫来源可能影响整体相关的GPCPD1。患者队列若有可靠组成估计，可检验组织组成对原关联的影响；没有就保留限制。ETNK1和SLC7A11先分清背景。PRODH2需合适的骨转移资料，UPP1需覆盖中性粒细胞的数据，当前图谱不能替代。
