# BRCA：原174关系FUSCC批量关联与117基因干预资源利用

## 本轮问题
停止围绕PYCR1同一CAF论文反复整理。对原174条直接关系开展完整FUSCC外部可评估性及关联分析，并从117基因已有122条文献记录发现干预资源入口。PYCR1记录用词更正见PYCR1_interpretation_amendment_CN.md，历史数值不改。

## 输入与范围
原174关系、73代谢物键、117基因；FUSCC作者594项极性代谢注释、作者处理代谢矩阵与门户TPM。按既有作者患者映射连接258个原发TNBC患者ID；同组织分装及跨队列基因型独立性未验证。原CAMP是作者映射标本，未升级其独立患者身份。所有矩阵和逐患者值留server165。

## 实际结果
### 外部批量分析已完成
73个代谢物键中：51个唯一作者标识匹配可用，21个无精确匹配，1个乳酸存在L/DL构型范围疑点。保留作者B(i)/B(iii)鉴定级别，不把标识匹配当成重新确认化学身份。
174条关系全部有去向：133条可计算（每条主分析n=258），39条不可评估，2条乳酸关系NEEDS_REVIEW。实际取得95个相关基因的门户表达；未匹配代谢物的关系不凭RNA覆盖冒充可评估。
主分析按计划174条统一BH：16条q<0.05，涉及13个基因。与原CAMP未调整相关比较：7条同向、8条反向、1条CAMP无可比较值（CHKB—choline）。因此不是16条成功复现。

同向且FUSCC本轮q<0.05的全部7条：

|---|---|---:|---:|
|OAT|glutamate|-0.189|0.0321|
|ASNS|glutamine|-0.307|0.0035|
|GLS|glutamine|-0.355|0.0035|
|FH|malate|+0.207|0.0174|

这些同向关系不要求CAMP也过显著阈值，不能称7条全部完成双队列显著复现。CAMP原效应/q、ER结果、FUSCC新效应/q均分列保留；符号比较不等于正式队列间差异检验。
8条反向关系也全部保留，包括SLC7A11—cystine、PMM1—mannose6phosphate、CHPT1—CDP-choline等。ASNS的glutamine关系同向，但glutamate和aspartate关系反向，不能只摘支持某个故事的底物。
排除既有身份警示患者的预定敏感性分析实际去除1例（n=257），133条可计算，19条q<0.05；主分析16条均保留，另外3条为GOT2—aspartate、PNP—inosine、AASS—lysine。不能因为这个版本显著更多就替代主分析。
GPCPD1—GPC输入经同一持久化TSV表示逐值确认一致，原rho=-0.040575、P=0.5224及区间复用；旧两关系q=1.00保留，新174范围q=0.95265。仍为外部未支持。GPI—G6P仍不可评估。

### 全117干预资源：完成首轮入口发现，设计核实仍为PARTIAL
复用122条文献记录（90个基因有记录，27个当前没有），取得67条记录对应的可读PMC正文；40条未获得可唯一解析的PMC全文入口，15条访问失败。机器提取后28个基因有数据集编号线索，获得66个GEO数据集设计元数据。没有编号不能写成无公开数据；有编号不能写成可运行的目标基因干预。
进一步读取了12条资源的具体模型/设计记录：KMO的GSE145661是直接siKMO，但仅2个样本，不能从每组1个获得生物重复差异推断；PYCR1仍有已登记疑点。CKB对应HIF1干预、SLC6A8对应缺氧、SOAT1对应FGFR1激活、SQLE对应未处理细胞系、PFKP对应共培养后细胞类别比较，均不能算目标基因自身干预。UPP1关联的尿嘧啶处理数据是代谢物扰动，可作为情境资料，不是UPP1基因敲除；PRODH2目前确认原始测序入口，未取得设计明确的处理后矩阵。
完整去向见all117_intervention_resource_inventory.tsv和manual_resource_design_notes.tsv。其余入口仍需逐项确认，不能宣称117个基因都已有经验证可用的干预数据。这一批没有新增干预矩阵检验，也未把PYCR1敲低后的其他基因变化当成它们自身的功能验证。

## 新手解释
外部关联回答“另一批TNBC患者里，某基因表达和某代谢物是否一起变化”。例如ASNS与谷氨酰胺负相关表示ASNS较高的肿瘤中谷氨酰胺往往较低；仍不能证明ASNS消耗谷氨酰胺造成肿瘤变化。
相比只围绕GPCPD1/GPI，本轮让其他候选获得了实际外部数值。ASNS、GLS、AFMID、SLC6A8、FH、OAT、NNMT都有同向线索；但原功能模型、CAMP稳健性和外部身份可信度必须共同考虑，不即时指定第一或第二候选。

## 限制/反证
这是作者注释下的匹配，非原始谱图重鉴定，B(iii)层级仍单列。只用极性594注释，不能把未覆盖写成FUSCC所有平台都未测。作者既有填补/处理保留，原始检测掩码未核实；本轮没有新增填补。不同队列正常参照/亚型/平台不同，本轮外部关联为肿瘤内未调整Spearman，未加纯度/亚型等协变量。与CAMP未调整方向作主要描述对照，ER调整数值另列；不作正式异质性或癌种特异性推断。
两套分析各固定174计划项（其中133有效），缺项只在BH内部以P=1占位，公开P/q仍NA。9999次双侧置换、2000次逐患者bootstrap点区间；独立性沿用作者ID。P的最小分辨率0.0001，不能精确排序同为0.0001的关系。所有266个rho及两族BH经独立实现核对通过。
资源检索只是现有文献的有界利用，不是系统检索所有数据仓库；全文可读不等于全文证据逐图审计。机器编号线索已去除SRP54这类基因名误命中。正式分析的适用性以具体模型、测量单位与重复设计为准。

## 当前决定
全117比较表追加外部覆盖、显著关系和资源状态，原199列逐值不变。允许其他候选依据实际外部和功能证据继续，不因旧10基因名单限制。PYCR1 CAF资料暂时收束；下一步不以修完其全部附件为前置条件。

## 下一步
优先核对新获外部证据的具体关系对应的干预资源及模型适用性。已找到的资源不合适时标明原因，不借另一个基因或处理条件凑验证。干预资源设计核实仍需继续，当前未启动新的大规模测序重处理。
