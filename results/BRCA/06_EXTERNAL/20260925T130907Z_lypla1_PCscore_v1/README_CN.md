# LYPLA1／LYPLA2：固定PC酰基链重塑评分与实测LPC 16:0

## 本轮问题

恶性上皮中LYPLA1较高的供者，是否同时具有更高的固定磷脂相关转录评分？同一基因集在CAMP组织RNA中的评分，是否与该患者实测LPC 16:0关联？LYPLA2按同一方法作平行比较，不作为阴性对照。

本轮按用户要求以名义P<0.05保留探索线索；完整q仍存档，不作为候选入场门槛。此前配对差值分析已完成，本轮不重算、不另算为新证据。

## 输入与范围

### 基因集在看关联前固定

使用[Reactome R-HSA-1482788：Acyl chain remodelling of PC](https://reactome.org/content/detail/R-HSA-1482788)，2026-09-25取得，数据库版本97。API的UniProt蛋白成员27个，既含反应相关蛋白，也含其他通路参与角色；不是27个独立催化酶。

在运行任何关联之前，按三个平台的精确基因身份、有效覆盖和非恒定表达固定24个共同成员。排除情况完整记录：

- **LPCAT4**：CAMP历史符号身份仍有限制，不强行对应现代蛋白。
- **PLA2G4B**：CAMP缺少精确符号对应。
- **PLA2G2E**：两套单细胞恶性上皮均未检出，不能计算有效标准化评分项。

LYPLA1和LYPLA2不进入评分；它们本来就不在此次返回的27成员中，排除规则仍在代码中显式执行。没有按相关性或P值删选成员。

24成员为：LPCAT1、LPCAT2、LPCAT3、MBOAT2、PLA2G10、PLA2G12A、PLA2G1B、PLA2G2A、PLA2G2D、PLA2G2F、PLA2G3、PLA2G4A、PLA2G4C、PLA2G4D、PLA2G4E、PLA2G4F、PLA2G5、PLA2G6、PLA2R1、PLAAT3、PLB1、PLBD1、PNPLA8、TMEM86B。

### 单细胞单位与评分

|数据|有效供者标签|实际恶性上皮细胞|每供者细胞范围|注释来源|
|---|---:|---:|---|---|
|Wu2021|20|24,489|124～4,053|作者celltype_major，经CELLxGENE提供|
|Pal2021_reprocessed|33|130,078|51～13,939|Chen2026对Pal2021的重注释，不是原Pal标签|

纳入至少20个恶性上皮细胞的供者，使用全部符合条件的细胞，不作WGCNA式抽样、不重新聚类。按作者供者标签汇总，不声称额外完成基因型身份验证。

每供者先相加原始counts，以该供者恶性上皮全部基因的总counts为分母，计算`log1p(基因总counts／全基因总counts × 10000)`。每个供者最终占一个观测单位，供者细胞数量不同不会产生多个独立重复。

在每个队列内部，每个评分基因按供者进行`z=(表达−队列均值)/队列样本标准差`；24个z值等权平均即评分。CAMP沿用作者RNA尺度，再按同一规则在60个肿瘤病例中标准化并平均。三个队列使用同一24基因及同一等权规则，但**分数绝对大小不可跨平台直接比较**。

### CAMP及一套背景敏感性

- 使用作者病例表核查后保留的60个组织类型一致肿瘤病例；精确RNA—代谢物连接沿用已有记录。
- 作者可用值敏感性为55例：LPC在作者`data`表有值。仍用同一作者处理尺度，不新增填补、不把该掩码冒充原始检测证明。
- 单一背景模型为ER＋2个组成相关主成分。先从已有MCP-counter标记中排除完整历史156基因及全部27个通路成员和两个比较基因，再按既定≥2标记且≥50%原覆盖门槛形成9类代理评分。
- 实际排除与标记重叠的KYNU、HAL；单标记CD8面板不进入PCA。前两主成分解释代理评分变异40.22%、23.91%。这些是修改版表达代理，**不是细胞百分比，也没有估计上皮比例或完整肿瘤纯度**。
- 同时纳入ER及组成PC，因此效应改变不能单独归因于某一细胞成分。没有进一步试其他背景模型。

### 固定检验范围

共8项：单细胞2队列×2基因=4项；CAMP评分—LPC主分析／可用值=2项；这两项各增加同一背景模型=2项。所有结果保留；BH8仅存档。

未调整模型用Spearman，99,999次双侧置换加一法；调整模型为秩变量对ER与两个秩化PC求残差后的相关，用ER组内Freedman–Lane残差置换。区间为4,000次整供者／整病例重采样的逐项95%百分位区间；调整模型在ER内分层重采样并重拟合残差模型，评分和PC定义保持固定。区间不计入选择基因集、覆盖和标准化方案的不确定性。

## 新手解释

1. **LYPLA1在两套单细胞中都呈正向点估计，只有Pal获得名义P支持。** Wu区间很宽，不能说已经实现稳定的两研究统计复现。这里比较的是供者恶性上皮的平均RNA状态，不是证明每个人内部LYPLA1较高的单个细胞都有同一状态。
2. **在CAMP中，该评分较高反而倾向伴随LPC较低。** 这是实际负向结果；它与“LYPLA1本身—LPC为正相关”是不同的变量关系，不可合并成一个方向一致的代谢机制。
3. 分数汇总了不同通路角色，其高低不是净生成／消耗速率。负相关不能直接解释为“LPC被消耗得更多”；也不能因此否定LYPLA1与脂质生物学有关。
4. LYPLA2本轮没有明确名义P支持，但尚未直接检验LYPLA1和LYPLA2的相关强度差异，不能据此宣称LYPLA1优于LYPLA2。
5. CAMP可用值及背景调整后仍为负向，但统计支持不足。它们与主分析效应差距有限，不能写成“调整后完全消失”，也不能说已排除全部组织组成影响。

## 限制／反证

- 评分是固定通路覆盖子集的自定义等权转录汇总，不是经过功能校准的代谢活性测量。低表达成员可能有较大测量误差，等权标准化也会给予其同样权重；本轮没有事后删去这些基因来优化结果。
- 供者数20和33较小，尤其Wu区间较宽。未做新亚型交互或治疗校正，不把亚型差异当作已解决。
- Wu／Pal与CAMP没有同患者连接。本轮通过共同基因集衔接证据，不拼接供者。CAMP是整块组织RNA，不能改称其分数为癌细胞内评分。
- Pal使用重处理及重注释数据，只作相应来源范围内的外部转录背景比较。
- 属于选定LYPLA1后的探索性专题，名义P支持不等于独立验证、靶点依赖或因果。q存档，不用它作为本阶段排除候选的门槛。
- 已有WGCNA未建立稳定脂质枢纽的限制仍保留。本轮固定Reactome评分不是对WGCNA模块的验证或替代解释。

## 当前决定

**保留Pal的LYPLA1—转录评分正向线索，以及CAMP的评分—LPC负向线索；不把它们拼成“LYPLA1升高→PC评分升高→LPC升高”的链条。**

LYPLA1仍保留既有直接患者关联、配对RNA和细胞表达背景。本轮提供的是更明确的限制：这个24基因汇总目前不能作为解释LYPLA1—LPC正关联的可靠中间环节。
