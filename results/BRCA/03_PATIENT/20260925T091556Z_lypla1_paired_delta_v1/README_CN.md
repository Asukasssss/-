# LYPLA1：同患者RNA变化与LPC 16:0／游离GPC变化

## 本轮问题

同一个人，肿瘤相对对应正常组织的LYPLA1 RNA增加越多，LPC 16:0是否也增加越多？游离GPC是否有相应关系？同时统计真实共同升降人数。

这是新的配对变化量分析，不是重算已有60个肿瘤标本之间的关联。既有统计保持原样。

## 输入与范围

- 使用已有作者病例表核实的45对组织类型一致的肿瘤—正常配对，连接RNA与代谢物。沿用作者配对身份，不声称完成基因型身份验证。
- RNA：GSE37751处理后基因表达矩阵，精确基因符号LYPLA1。
- 代谢物：CAMP BRCA1 `data_imputed`作者处理值；分别计算肿瘤减对应正常。未增加转换、归一化或填补，不把差值称为浓度倍数。
- 精确特征：`1-palmitoyl-GPC (16:0)`（KEGG:C04102）和`glycerophosphorylcholine (GPC)`（KEGG:C00670），两者不得混用。
- 可用值敏感性：仍使用同一处理尺度，要求代谢物在作者`data`表中肿瘤、正常两侧均有有限值；LPC 16:0为28对，游离GPC为45对。这个掩码不是重新核实的原始检测掩码。
- 分析前固定4项：2个代谢物×2种分析；四项共同BH校正。GPC的两个子集完全相同，保留两行及同一随机种子，但不称为两次验证。
- Spearman相关；99,999次双侧绝对值置换检验，P=(极端次数+1)/100,000。10,000次整对病例bootstrap给出逐项95%百分位区间。全部保留，不追加删除离群点或择优模型。

|LPC 16:0|可用值敏感性|28|+0.2173|−0.2184～+0.5619|0.26469|0.52938|

## 新手解释

**30/45共同升高回答“是否在同一批人中一起变高”；ρ=0.322回答“升高幅度是否相伴”。两个问题不能互相代替。** 本轮没有对共同升降人数另做显著性检验，也不把每一对称为分别显著。

目前观察到LPC方向上的探索性线索，但缺失敏感性支持有限。28对子集中点估计仍正向，区间包含负值与零；差异也可能与样本减少或入选病例不同有关，不能仅凭结果减弱断言原关联全部由填补造成。

GPC中虽然23/45对为“RNA升高、GPC降低”，但变化幅度相关接近零。多数病例方向相反，不等于RNA升得越多、GPC就降得越多。

## 限制／反证

1. 新检验是在已经关注LYPLA1之后提出的同队列探索；BH4不覆盖整个项目此前的选题与全部历史分析。
2. 本轮是整体组织配对差值。组织组成、测量误差和肿瘤／正常背景均可能影响它；不是同一恶性细胞内的关系，也没有新增ER或细胞组成调整。
3. 对照为作者对应正常／邻近组织，不等于健康人组织。配对身份继承已有作者记录。
4. 变化量相关不是因果、介导比例、酶活、运输速率或代谢通量；它也不能直接与Wu／Pal细胞配成同患者多组学。
5. 旧肿瘤内部LPC关联ρ约0.482、q=0.017及可用值ρ约0.518、q=0.0255继续保留，回答不同问题。本轮未通过BH4不覆盖或推翻旧统计，也不能将旧q贴到新差值分析。
6. GPC敏感性等同主分析，不能算一次额外复现。两种代谢物、两种分析均完整呈现，不仅展示有利的LPC主分析。

## 当前决定

LYPLA1—LPC 16:0继续作为潜在靶点挖掘中的患者线索，新增标签为：**配对变化主分析名义支持；联合FDR未支持；可用值敏感性支持不足**。不能升级为已建立稳定变化量联系或机制。

本轮的信息增量是补清真实共同变化人数与变化幅度之间的联系，而非证明LYPLA1调控LPC。没有因为这次结果删除LYPLA1，也没有增加其他基因或自动开启新的单细胞／机制分析。
