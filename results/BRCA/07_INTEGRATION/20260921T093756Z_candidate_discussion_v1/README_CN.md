## 新手解释
留出范围的意思是：拿掉任意一位病例后，相关系数会落在什么范围。本轮三条关系都没有因为拿掉单个病例而翻转方向，且rho仍为正。这增加了对“不是由某一例单独造成”的有限信心，但不说明结果已在其他患者中验证，也不消除亚型、组织组成或多个病例共同影响。

公开图中的横线是20次留出的最小—最大范围，不是95%区间。20次留出高度重叠，不能算20次独立验证。旧q=0.0489和0.07335仍分别保留，不重算成两项校正；PNP两条关系共享病例和基因。

## 限制/反证
MDH1在Tang的强关联与FUSCC接近零共同保留；GSE42568的MDH1 RNA平均较低也保留。组织间差异与肿瘤内部相关回答不同问题，不能互相推出基因应抑制或激活。MDH1历史功能记录对特异遗传干预/药物专属性仍有疑问；MDH2文献不得移用。

GPI明确标为“FUSCC缺测；Tang已评估但未支持G6P/F6P正关联”，不再统称等待外部数据。没有做正式队列间效应差异检验，Tang负点估计不等于相反生物学作用已成立。

本轮未重算置换P及BH；也未将GSE42568的57个差异基因设为候选门槛。全部117保留。功能、患者、单细胞定位、RNA背景分列；原历史工作优先级未改写，读者应看新“本轮定位”列，避免把历史标签误当新结论。
