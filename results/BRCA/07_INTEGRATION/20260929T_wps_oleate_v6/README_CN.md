# WPS第9页：油酸反应角色补充

本轮问题：用户指出未说明油酸在LYPLA1映射中的作用。

输入与范围：当前25页WPS第9页，仅替换生化框中两行文字。

实际结果：补入“含油酰基 PC → 2-酰基 LPC + 油酸”；标明油酸是sn-1位水解释放的脂肪酸产物。实际WPS打开保存并导出核对。

新手解释：PC为磷脂酰胆碱；该反应水解PC的sn-1油酰基，释放油酸，留下2-酰基LPC。与上方LPC(16:0)水解生成GPC与棕榈酸为两条反应。

限制/反证：反应为简式，省略水与质子。底物为1-油酰基-2-酰基PC；自由油酸不一定由该反应贡献，患者丰度关联不证明酶活或净通量。没有新增统计。
