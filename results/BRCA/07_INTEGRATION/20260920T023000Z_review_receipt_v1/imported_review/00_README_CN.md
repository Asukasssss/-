# BRCA fb5924b：全候选后续结果复核

检查用户提供的新结果是否与公开代码、参数和重点数值一致；判断它怎样改变后续研究安排。
本轮读取版本：fb5924b。没有重新筛选患者相关性，没有删除候选，没有修改GitHub。

## 3. 总体判断
本批适合继续作为探索性证据底表。代码对全部117基因和174条关系进行处理，不是把117筛成2。
公开报告的43个双来源稳定基因，以及各模型171项可评估检验等数量，是本批执行端报告。
本轮检查三份核心脚本、方法参数、标记覆盖和验证日志，并抽查17个基因、14条关系；
没有在本会话逐行重算43个计数、348行完整BH或144列历史字段保留情况。
本包是本轮复核交付，**不是整个fb5924b仓库的镜像或新的全117筛选表**。

## 4. 主要发现
### 组成评分
主模型为ER + 9个符合覆盖要求的修改标记评分的前2个PC；
次模型为ER + 单核、内皮、成纤维评分。
代码先排除全部117候选与标记库的交集，实际移除了KYNU、HAL；
这降低了候选表达直接进入自身协变量的自包含问题。
但修改版评分没有额外生物学标定，评分仍不是真实细胞百分比。
原R实现数值核对是执行端日志，并不证明修改版评分准确反映所有细胞组成。
约64.5%指评分PCA的变异解释比例，不是已消除64.5%的混杂或组织组成。

### 患者/标本关联
必须用同一个可用性子集中的ER基线作对照，而不是任意选择较早版本。
- GPCPD1—GPC：ER rho=-0.5152；主模型-0.4597,q=.0342；次模型-0.5250,q=.0171。
- GPI—G6P：ER rho=.4582；主模型.4492,q=.0342；次模型.4549,q=.0513。
前者在两模型中仍有统计支持；后者效应大小接近，主/次模型阈值不同不能当成作用有无的分界。
二者都是同一批CAMP标本上的敏感性，不是外部复现，也不能定位哪个细胞执行了代谢反应。

NNMT—1-MNA、ASNS—谷氨酰胺、PNP—鸟嘌呤等在不同模型中减弱；
这值得记录，但不能仅凭变化断言原因就是细胞比例，或证明没有功能。
同一基因有多个代谢物时，每套模型的best关系可能不同：SORD、PPA1就是例子。
对比须锁定relation_id，不能跨代谢物比较后声称rho反转。

### 细胞来源
43个规则是“两个研究最高类别一致，且各自重采样保持率≥80%”。
保持率不是80%的患者同方向、不是80%真实概率、不是功能检验。
最高与次高类别在同一数据中选定，因此配对重采样区间是描述性、选择后的区间。

GPI的Wu保持率99.9%，但最高类与次高类共同具备覆盖的18个来源标签中有12个差值为正。
AFMID在Wu满足本轮保持率规则，但8个共同来源标签中仅3个为正。
这说明总体均值的排序稳定性与逐供者一致性不是同一个指标。

前轮82个用的是两个研究共有8类中的最高类别；本轮按各自完整可评估类别并增加稳定性规则。
因此不能把82→43简单解释成39个“失效”。
BBOX1在Wu全部类别最高为非恶性上皮、Pal为恶性上皮，便是口径差异的例子。

PMM2的最高类别仍都为恶性上皮，但Pal保持率72%，未达本轮双80%规则；
这不否定其既有情境性功能，仍不能据表达判断ESR1突变/耐药背景。
PYCR1在当前数据恶性上皮最高，不否定既有乳腺癌CAF中的脯氨酸-胶原功能研究；
表达最高类不能自动替换直接干预所支持的作用细胞。

## 5. 当前应如何推进
建议先固定本轮版本，不再为跨过q=.05增加模型或尝试种子。
少数具体问题并行：
- GPCPD1—GPC、GPI—G6P：优先核实是否有可直接复用的外部同患者代谢物/RNA或蛋白数据；
  先核实覆盖，再决定计算，不承诺外部复现一定成功。
- PYCR1等作用背景与最高表达类别不同的候选：保留癌细胞与CAF两种解释，围绕已有数据提出明确问题。
- NAMPT/BCAT1和SPHK1/CDO1等：依据现有细胞亚群注释和功能出处选择少数问题，不自动给43个全部追加流程。
- PMM2、UPP1、PRODH2：特殊突变、免疫细胞或骨转移数据不足时保留相应范围，不用普通原发瘤图谱替代。

全117继续保留。细胞来源稳定不能替代患者代谢关联，更不能替代功能干预。

## 6. 本轮实际验证与未验证

全部122条原文献的真伪和结论也没有在本轮重审。
