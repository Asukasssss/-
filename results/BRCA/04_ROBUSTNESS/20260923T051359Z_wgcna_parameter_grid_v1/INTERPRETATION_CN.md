# 参数比较的具体判断

- LYPLA1在8组Wu设置中均未进入模块前20%；名次比例39.3%～60.1%，kME为0.493～0.519。这组合理邻域参数没有把它变成稳定靠前的模块成员。
- power10的95/242比基线127/213靠前，但与原模块的基因集Jaccard仅0.0412，Pal kME降至0.299。不能把这个版本挑出来称为最佳结果。
- 原软阈值评估中，power10的R²=0.682，未达到基线启发阈值0.8；power14平均连接度=4.064，低于基线规则5。二者用于敏感性检查，不能因名次较好替换主模型。基线power12的R²=0.812，平均连接度=9.350。
- Pal使用Wu的固定模块成员集合时，LYPLA1在7/8组进入相对前10%，但并非Pal独立发现了相同模块。基线pink模块整体的供者层面Zsummary仅1.321，未获得明确保留支持；不能只报Pal的相对前列而隐去这个限制。
- LYPLA2、PCYT2、ETNK1、GPCPD1等也全部记录，没有因为排名不靠前而删除。20个专题基因中8个至少一组可排名；其他12个未入固定输入或始终未归入有效模块，不能算作功能阴性。
