# ccRCC 本轮版本决定

用户于2026-09-25明确分配ccRCC，沿用BRCA发现至单细胞来源逻辑。

1. `20260925T143000Z_discovery_v1` 是ccRCC4首版。仅CAMP总表病理筛选后为14位肿瘤患者、13对。后来原研究MetaData_M5揭示另外2位患者（3标本）与总表病理冲突：嫌色细胞癌、未分类癌。此首版的发现、映射、患者数值仅作历史，**不进入当前主结论**。原始数值保留，无覆盖。
2. `20260925T155000Z_ccrcc4_histology_v2` 是当前ccRCC4版本。要求CAMP和原研究均明确Clear Cell；任何冲突按整患者排除。原76标本共排除3位患者的5标本（含首版已排除的髓质癌），保留71标本、12位患者、12对。
3. `20260925T151000Z_ccrcc3_v1` 是ccRCC3发现、映射、主关联及RNA版本。MetaData_M4提供作者SUBJECT_ID；只规范化SAMPLE_NAME的点号/连字符，绝不从名称猜患者。17位患者均有配对。
4. ccRCC3治疗敏感性采用 `20260925T155500Z_ccrcc3_therapy_v2`。原MetaData_M4的NO组有1位患者在原研究master_mapping记为Cabozantinib。组合两个字段后再分层置换。主关联、可用值关联和RNA原数值完全复用。作者master_mapping也独立核实114个RNA连接及全部67个肿瘤的clear cell病理；正常组织不强行要求肿瘤病理字段。
5. `20260925T153000Z_source_union_v1` 单细胞覆盖两队列及版本历史并集157基因，包含当前154基因；不因版本改变删除已分析历史基因。GSE159115是表达背景，不能当代谢物—基因关联的外部复现。
6. 两队列分别检验、分别BH，不合并标本，也不因作者患者标签不重叠就宣称独立研究复现。原CAMP612项及其310个q<0.05统计仍冻结，不能用本轮结果覆盖。

映射采用有明确边界的项目已审定人类生化库，未映射项保留NEEDS_REVIEW；不是穷尽性生化注释。第二独立单细胞研究、现成UMAP坐标、新增功能与机制验证未完成，不写成阴性或已验证。
