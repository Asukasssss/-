# ccRCC样本设计与历史结果

问题：能否按BRCA主线建立患者独立的ccRCC分析？

输入：CAMP作者矩阵、MasterMapping和ccRCC3原始工作簿；逐样本表只留server165。

实际结果：ccRCC3的114个作者映射标本均为透明细胞癌，纳入114个透明细胞癌标本、17位作者患者、17对患者。多个区域先在患者×组织内等权取均值。全矩阵787特征，作者两组织均保留711项。原癌种冻结612项及其P/q原样保存。

新手解释：标本数不是患者数；同一患者的多个区域不能当作多位患者增加样本量。

限制：治疗背景混合，主要为免疫治疗；不是治疗效果比较。作者MetaData_M4提供明确患者连接；仅规范化样本ID点号为连字符，并未从名称推断患者。跨队列独立性尚未证实。矩阵内未被作者跨组学表确认的标本不擅自扩入。

当前决定：按已冻结设计执行ccRCC3患者均值配对分析；保留ccRCC3状态。

下一步：全量发现、直接关系、患者关联、RNA背景、全候选单细胞来源。
